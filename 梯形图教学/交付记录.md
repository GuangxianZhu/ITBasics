# 交付记录

> 实现方：每完成一个阶段，在本文件**末尾**按模板追加一节。不要修改已有的节。
> 验收方：只看上次验收以来新增的节 + `git diff` + 测试结果。

## 验收方法（验收方用，实现方可忽略）

```bash
cd 梯形图教学
LAST=$(grep -oP '已验收基准: \K[0-9a-f]{7,40}' 交付记录.md | tail -1)  # 上次验收点
(cd tests/acceptance && sha256sum -c SHA256SUMS)                # ① 验收测试没被改
python -m pytest tests -q                                       # ② 测试
git diff --stat $LAST..HEAD -- .                                # ③ 改了哪些文件
git diff $LAST..HEAD -- . ':!docs/shots'                        # ④ 只看新增/改动的代码
# ⑤ 看本文件新增的节、看 docs/shots/P<n>_*.png
# 通过后: 在本文件末尾追加 "## P<n> 验收通过" 一节，写一行  已验收基准: <commit hash>
```

不通过时，验收方在本文件末尾追加"验收意见 P<n>"一节，实现方逐条处理后再追加交付节。

# 统一查询器 需求与用例（v0.1）

## 1. 目的
现在查一个问题要来回开十几个 Excel。
做一个工具，把以下文件读进来、自动建立关系，输入一个东西就能看到所有相关信息。

## 2. 对象文件
| 文件 | 主要内容 |
|---|---|
| 报警文件 | 报警号、内容、触发条件 |
| 参数文件 | 参数号、名称、设定值/范围 |
| 固定配置文件 | 功能/单元的有效与否 |
| 地址符号文件 | 符号 → 各机台的实际地址 |

## 3. 关系（核心）
```
报警 ──→ 符号 ──→ 机台A的地址 / 机台B的地址 …
  │        ↑
  └→ 参数 ─┘
固定配置 → 决定哪些报警/功能有效
```
所有文件都挂到「符号」上，符号是中心。

## 4. 功能需求
1. 输入**报警号** → 相关符号、各机台地址、相关参数、有效条件
2. 输入**符号或地址** → 反查用到它的报警、参数
3. 输入**参数** → 影响的符号、报警
4. 指定**机台** → 只显示该机台的地址
5. 结果可**导出 Excel**
6. 源文件更新后，**重新读取**即可同步

## 5. 用例
| # | 场景 | 输入 | 想看到 |
|---|---|---|---|
| UC1 | 故障调查 | 报警号 | 触发信号、地址、阈值参数 |
| UC2 | 回答客户 | 参数 | 改了它会影响什么 |
| UC3 | 版本/机台差异 | 报警号 + 两台机台 | 地址、条件的差异 |
| UC4 | 写设计书 | 要改的符号 | 影响范围一览 |
| UC5 | 回复外包 | 符号 | 定义在哪、谁在用 |
| UC6 | 一致性检查 | （全部） | 不存在的地址、没人用的参数 |

## 6. 第一版范围（MVP）
- 只做：**报警 → 符号 → 1台机台地址**
- 输出：Excel 一张表
- 跑通后再加参数、配置、多机台

# 外接屏夜间调暗（Night Dimmer）

晚上自动把外接显示器调暗，开机自动启动。
用显卡 Gamma 斜坡调暗，切窗口、Alt+Tab、开始菜单、UAC 都不会突然变亮。

## 安装
1. 把本文件夹放到固定位置（装好后别再移动）
2. 双击 `安装.bat`（需要已安装 Python）
3. 右下角托盘出现绿色月牙图标即为运行中；之后开机自动启动

## 默认
- 19:00 ～ 07:00 调暗到 50%，前后各 30 分钟渐变
- 只调外接屏（只有一块屏时调这一块）

## 托盘右键菜单
自动 / 一直调暗 / 不调暗、夜间亮度、夜间时段、主屏也调暗、开机自启、退出（恢复亮度）

## 想比 50% 更暗
右键 `解锁更暗(可选).reg` → 合并（需管理员），重启电脑。

## 注意
- 建议关闭 Windows 自带「夜间模式」，两者可能互相覆盖
- 开启 HDR 时可能无效

# YouTube 字幕下载器

粘贴 YouTube 链接，一键下载字幕，可转成 SRT / 纯文本。带图形界面。

## 使用
1. 双击 `启动.bat`（需要已安装 Python；第一次会自动安装 yt-dlp、curl_cffi、deno，之后每次启动顺便更新）
2. 粘贴链接（可多个，一行一个；播放列表链接会下载整个列表）
3. 可先点「查看可用字幕」，看这个视频有哪些语言
4. 勾选语言和格式 → 「⬇ 下载字幕」
5. 默认保存到 `下载\YouTube字幕`，点「打开文件夹」直接看

## 选项说明
| 选项 | 说明 |
|---|---|
| 语言 | 日/英/简中/繁中可勾选；其他填代码，如 `ko`, `fr`；填 `all` 下载全部 |
| 翻译字幕失败时改下原文字幕 | 自动翻译字幕（如英文视频要中文）YouTube 限流很严，常报 429；失败时自动改下视频原文字幕，拿去给 AI 翻译即可 |
| 没有人工字幕时用自动字幕 | YouTube 自动识别的字幕，还能自动翻译成几乎任何语言（比如日语视频直接拿 zh-Hans） |
| SRT | 带时间轴，可配合播放器使用 |
| TXT 纯文本 | 去掉时间、去掉自动字幕的重复滚动行，适合阅读/丢给 AI 做摘要 |
| TXT 带时间 | 每行前面加 `[时:分:秒]`，方便定位 |
| 保留原始 VTT | YouTube 原始格式，一般不需要 |
| 借用浏览器登录状态 | 只在报“Sign in to confirm you're not a bot”时才用；firefox 最稳，Chrome/Edge 需先关闭浏览器，新版常读取失败 |

## 常见问题
- **报 403 / Unable to extract**：YouTube 改版了，点「更新 yt-dlp」后重开程序
- **报 429 / 请求太频繁**：程序会自动等 5 / 20 / 60 秒重试 3 次。最常见于**自动翻译字幕**（zh-Hans 等），建议直接下原文字幕再翻译；还不行就等一会儿或借用浏览器登录状态
- **No supported JavaScript runtime / impersonate target**：缺少 deno / curl_cffi，重新双击 `启动.bat` 或点「更新 yt-dlp」即可装上
- **没有所选语言的字幕**：先点「查看可用字幕」确认；勾上自动字幕一般都有
- 不需要 ffmpeg，格式转换由程序自己完成

## 原理
```
链接 → yt-dlp 读取视频信息（不下载视频）→ 下载字幕 .vtt
     → 本程序解析 VTT：去掉 <c> 时间标签、合并滚动重复行
     → 写出 .srt / .txt
```
YouTube 自动字幕是"滚动式"的：每条字幕会把上一行再显示一遍，直接转文本会每句重复两次。
程序记住最近出现过的几行，只保留新出现的行，所以 TXT 里每句只出现一次。

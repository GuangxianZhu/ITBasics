# 建模规范（Qwen 每次建模前必读）

你在用 Python 脚本驱动 Blender 建模。你写的脚本放在 `models/` 里，由 `run_model` 工具交给 Blender 执行，
执行完会自动做三件事：**检查零件之间有没有穿插/悬空**、**渲染四视图**、**保存 .blend**。
你看不到 Blender 界面，只能靠 **检查报告 + 四视图图片** 判断自己做得对不对。

## 一、坐标和单位（最容易错的地方）

1. 单位一律 **毫米 mm**。
2. **+Z 朝上**，地面是 `z = 0`。所有零件都应该在地面以上（最低点 z ≥ 0）。
3. `at=(x, y, z)` 永远是物体 **包围盒的中心**，不是底面。
   - 放在地面上、高 H 的物体：中心 z = `H / 2`
   - 叠在另一块板（上表面高度 `TOP`）上面、高 H 的物体：中心 z = `TOP + H / 2`
4. 正视图是从 **-Y 往 +Y** 看（看到 X-Z 平面），右视图是从 **+X 往 -X** 看（看到 Y-Z 平面），俯视图从上往下看。
5. `axis='X'/'Y'/'Z'` 是圆柱、管、回转体的轴线方向。横放的轴用 `axis='X'` 或 `axis='Y'`。

## 二、写脚本的规矩

1. 第一行 `import qbkit as K`，第二行 `K.reset()`。
2. **所有尺寸先写成大写变量**放在脚本开头，后面的位置全部用变量算。不要在 at 里写死算好的数字，
   这样改一个尺寸，相关零件会一起跟着动，不会错位。
3. 有配合关系的东西（孔和螺栓、轴和轴承孔）**用同一组变量**算位置。
4. 每个零件起有意义的英文名：`base_plate`、`shaft`、`bolt_1`。名字以下划线 `_` 开头的物体不参与检查（可以当辅助物体）。
5. 一个零件由几块拼成时，用 `K.join(a, b)` 合成一个；要挖槽、打孔用 `K.cut(target, tool)` / `K.hole(...)`。
6. 材质用 `K.mat(name, '#rrggbb', metal=, rough=)`，不同零件用不同颜色，四视图里才分得清。
7. 想核对尺寸时可以调用 `K.info(obj)`，输出会出现在运行日志里。

## 三、检查报告怎么看

| 段落 | 意思 | 要不要改 |
|---|---|---|
| 【结果】脚本运行出错 | 脚本有语法/参数错误，看报错行号 | 必须改 |
| 【零件】 | 每个零件的包围盒尺寸和 x/y/z 范围 | 拿来核对尺寸、位置 |
| 【穿插】 | 两个零件的实体互相嵌进去了 | 必须改（除非设计上就要压进去，见下） |
| 【接触】 | 表面贴合 | 正常，螺栓头压在板上就是接触 |
| 【悬空】 | 这个零件顺着接触关系连不到地面，飘在空中 | 必须改，报告会写差多少 mm |
| 【低于地面】 | 零件最低点 z < 0 | 必须改 |

**设计上允许的穿插**（例如过盈配合、销钉压进孔里、焊在一起但没 join）：在脚本最后写
```python
ALLOW_TOUCH = [('pin_1', 'base_plate')]
```
不要为了让检查通过而乱加 ALLOW_TOUCH。能 join 的就 join，有间隙的就留间隙（孔比轴大 0.2~0.5 mm）。

## 四、工作流程（每次都这样做）

1. 读需求，**先在心里列出零件清单和每个零件的尺寸、位置**（中心点怎么算）。
2. 第一次做这类东西时，先用 `read_file` 看一下 `examples/` 里的范例。
3. `write_model` 写出完整脚本。
4. `run_model` 运行，**仔细读报告，再看四视图**：
   - 报告有问题 → 找到原因 → 用 `edit_model` 或 `write_model` 修改 → 再 `run_model`。
   - 报告没问题 → 对照需求检查四视图：形状对不对？比例对不对？孔、槽的位置和数量对不对？
5. **每次修改之后都必须重新 `run_model`**，不能改完就说"完成了"。
6. 报告没问题、四视图也符合要求后，调用 `finish`，用几句话说明做了哪些零件、主要尺寸、还有什么没做到。
7. 如果连续 3 次修改都解决不了同一个问题，换一种建法（比如把一个复杂零件拆成几个简单零件再 join）。

## 五、常见错误

- 把 `at` 当成底面位置 → 零件一半埋进地面或别的零件里（报告会出现【穿插】或【低于地面】）。
- 横放的圆柱忘了写 `axis` → 竖起来了（看四视图就能发现）。
- `cut` / `join` 之后还去用 tool 那个变量 → tool 已经被删除了，会报错。
- 打孔的 at 给的是孔的中心，孔的轴向不要漏写。
- 法兰、端盖这类盘状零件和别的零件同轴时，半径要用变量算，别写超出底座范围（会和底座穿插）。
- `polar()` 阵列时 `center_pt` 要给阵列的回转中心，不是零件自己的中心。

## 六、qbkit 函数速查（全部单位 mm，at = 中心点）

```
reset()
mat(name, hexcolor, metal=0, rough=0.5)
box(name, size=(x,y,z), at, mat, bevel=0)
cyl(name, r, h, at, axis='Z', mat, seg=64, bevel=0)
cone(name, r1, r2, h, at, axis='Z', mat)          # r1=轴向负端半径, r2=正端半径
tube(name, r_out, r_in, h, at, axis='Z', mat)
sphere(name, r, at, mat)
revolve(name, profile=[(半径, 轴向位置), ...], at, axis='Z', mat)   # 闭合轮廓，绕轴旋转一圈
extrude(name, outline=[(x,y),...], h, holes=[[(x,y),...]], at, axis='Z', mat)
circle_pts(r, n=48, cx=0, cy=0)    rrect_pts(w, d, r)                # 给 extrude 用的二维点列
pipe(name, points=[(x,y,z),...], r, mat, sides=16, smooth=True)     # 管子、线缆
helix_pts(r, pitch, turns, at)                                      # 弹簧路径，配合 pipe
cut(target, tool)      join(target, other)                          # 布尔，tool/other 用完自动删除
hole(target, r, at, axis='Z', depth=None)                           # depth=None 表示打穿
copy(obj, name, at=None, rot=None)
polar(obj, n, axis='Z', center_pt=(0,0,0), prefix=None)             # 返回 n 个零件（含原件）
rotate(obj, deg, axis='Z', pivot=None)    move(obj, dx, dy, dz)
bounds(obj) -> (最小角, 最大角)    center(obj)    info(obj)
```

## 1. 项目一句话

用户（朱）家里的 UE 5.8.3 工程 **VillaVR**，关卡 **L_Courtyard**（基克拉泽斯式院落别墅），用 Quest 3 + Virtual Desktop 做 VR 预览。场景几乎全靠脚本生成，Claude 远程操作用户电脑来改。用户不懂 UE，只给目标，不会帮你点编辑器。

## 3. 现状（截至 2026-10-18）

1. 房子：约 1000 个体块 → 合并成 122 个带倒角网格（`court_geom.glb`），PBR 贴图（ambientCG）。
2. 声音 11 处、能抓的东西 20 件、黄昏氛围。
3. 烘焙光照（forward + MSAA，VR 约 90 帧）；Lumen 在 VR 里不到 60 帧，别用。

5. 手部菜单：**调整时间**（黄昏/上午/正午/下午）+ **转向角度**（45/30）；左右摇杆都能瞬间转向；Restart 重载当前关卡。逻辑在 `BP_XRPawn` 的 `Court*` 函数和 `WBP_Menu` 的 `Court*` 函数里。

## 4. 最快路径（照做）

### 4.1 连上（目标：2 分钟内）
1. `device_request_folder_access` 一次要两个文件夹：`~/Documents/UE-MCP-Tools`、`~/Documents/Unreal Projects`。
2. 在 device_bash 里测：
   ```bash
   cd "$HOME/mnt/UE-MCP-Tools/court/remote"
   echo 'import unreal; print("ready", unreal.SystemLibrary.get_engine_version())' > /tmp/r.py && ./uepy.sh /tmp/r.py
   ```
   - 出 `ready` → UE 开着，远程工具已自动启动，直接干活。
   - 卡住没输出 → UE 没开。让用户双击 bat，或者用 computer use：Epic 启动器 → 左上"启动 5.8.3" → 项目浏览器里双击 VillaVR（**别双击启动器里的工程缩略图**，.uproject 没关联，会报错）。约 30 秒后再测。
3. 要重启 UE（比如改了插件）：`./uepy.sh restart_ue.py`，约 30 秒自动回来，不用点任何东西。

### 4.2 工具（都在 device_bash 里跑，路径 `court/remote/`）

| 命令 | 作用 |
|---|---|
| `./uepy.sh 脚本.py 参数…` | 在编辑器里跑 Python，打印输出（**脚本放 `/tmp` 或别处**，`pyq/` 里的文件跑完就被删） |
| `./mcp.sh <工具集>.<工具> '<json>'` | 调 UE 自带 MCP 的工具；`./mcp.sh describe <工具集>` 看工具和参数 |
| `./dsl.sh <图表refPath> 文件.lisp` | 用蓝图 DSL 往函数图表里写节点（自动切英文→写→切回中文） |
| `./uepy.sh nodes.py <蓝图> <图表名> '<正则>'` | 查节点的**当前**真实名字 |
| `./uepy.sh pins.py <蓝图> <图表…>` / `links.py` | 检查引脚值 / 连线 |
| `./uepy.sh pie_start.py` / `pie_stop.py` / `pie_shot.py 名字` | 桌面模式运行、停止、截图（`Saved/Screenshots/WindowsEditor/`） |
| `./uepy.sh lang.py en` / `zh-Hans` | 切编辑器语言 |

常用 MCP 工具集：`editor_toolset.toolsets.blueprint.BlueprintTools`（add_function_graph / add_function_param / add_variable / write_graph_dsl / compile_blueprint / find_nodes / get_node_infos）、`UMGToolSet.UMGToolSet`（AddWidget / ToggleWidgetAsVariable / BindToEventProperty / GetWidgetDescription / CompileWidgetBlueprint）。

Python 里也有 `unreal.BlueprintGraphEditor`（UE 5.8 新增）：`get_graph_editor_by_name`、`create_node_from_name`、`list_all_nodes`、`remove_nodes`、`list_nodes_with_errors`；引脚用 `BlueprintEditorLibrary.list_all_pins(node)`，连线 `pin.try_create_connection(other)`。

### 4.3 改蓝图的固定流程
1. **先备份** 要改的 `.uasset`（复制到 `Saved/BeforeClaude_xxx/`）。
2. `add_function_graph` 建函数 → `add_function_param` 定参数类型（`float`/`int`/`string`，`input_param:false` 是返回值）。
3. `./uepy.sh lang.py en` → `nodes.py` 查要用的节点名 → 写 `.lisp` → `./dsl.sh` 写入 → `lang.py zh-Hans`。
4. `pins.py` / `links.py` 核对（DSL 回读 `read_graph_dsl` 显示的参数不可信，以 pins.py 为准）。
5. 编译（`BlueprintEditorLibrary.compile_blueprint`），看 `list_nodes_with_errors/warnings` 和 `bp.status`。
6. `EditorAssetLibrary.save_asset` 保存。
7. PIE 里用 `pawn.call_method("函数名")` 直接调用测试，截图看。
8. 新脚本/DSL 放进仓库，README 加一节，push main。

UMG 按钮：`AddWidget`（Button，父 `VerticalBox_48`）→ 再加 TextBlock 当子项 → Python `unreal.load_object(None, ".../WBP_Menu.WBP_Menu:WidgetTree.按钮名")` 复制原按钮的 `widget_style`、slot 的 `padding/size`、文字的 `font/color_and_opacity` → `ToggleWidgetAsVariable` → `BindToEventProperty(OnClicked)` → Python 在 EventGraph 里 `create_node_from_name("CallFunction|函数名")` 并把事件的 `then` 连过去。Python 本身改不了控件树。

参考：第五轮的全部 DSL 在 `c11_menu/dsl/`，辅助脚本在 `c11_menu/helpers/`。

## 5. 坑（都踩过，别再踩）

1. **中文界面下 DSL 接错执行引脚**（"Could not connect pin then to Object"）→ 必须在 `en` 下写。`dsl.sh` 已自动处理。
2. **节点名每次启动都可能不同**，而且中英混杂（这次是 `工具|流程控制|Switch|SwitchonInt`，重启后变成 `Utilities|FlowControl|Switch|SwitchonInt`）→ **永远先用 nodes.py 查，别照抄旧 DSL 里的名字**。DSL 自带的 `switch int`、`select`、`%`、`if` 别名常常找不到节点：用查到的全名，比较用 `Math|Float|NearlyEqual(Float)`，选择用 `SelectFloat` / `SelectString`，分支用 `IsValid` 宏或 Switch 的多出口写法。
3. **调用函数时第一个位置参数会进 `self`** → 一律用关键字参数 `:Pitch -7.0`。
4. `get_node_type_pins` 会**真的在图表里建节点**：在临时图表里用，用完删图表。
5. `remove_function_graph` 后立刻用同名重建会变成 `xxx_0`：先 `unreal.SystemLibrary.collect_garbage()`。
6. 模板自带图表 `read_graph_dsl` 读出来是空的：用 `find_nodes` + `get_connected_subgraph` / `get_node_infos` 看。
7. 不纯函数（带执行引脚，如 `GetCurrentLevelName`）只连数据线会被编译器裁掉，要串进执行链。
8. MCP 的 `call_tool` 要把 `toolset_name` 和 `tool_name` 分开传（`mcp.sh` 已处理）。
9. 退出 UE 时如果 `/Engine/BasicShapes` 是脏的会弹保存框：选"不保存"，**别保存引擎资产**。
10. PowerShell 做 MCP 中转连不上本机 8000（原因没查清），编辑器外的 python.exe 也卡住；在编辑器里开后台线程（`mcp_thread.py`）可以。
11. 场景本身的坑（导航、碰撞、烘焙、植物材质）见 README 坑 1–19。

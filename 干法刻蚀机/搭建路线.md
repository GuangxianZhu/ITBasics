# 干法刻蚀机教学项目 · 搭建路线

目标：做一台**原创的 ICP 导体刻蚀机**教学模型，同一份数据出三种形式：

1. **Blender 脚本建模** → glb（每个零件带中文名、材料、作用、爆炸路线）
2. **网页**：结构查看 + 原理实验 + 操作台（离线 html + claude.ai 网页版）
3. **VR**：导进 MyVRToyBox，以后再加交互

不对应任何厂家的具体型号，外形和商标都不照抄。结构按专利和公开资料，尺寸按 300 mm 晶圆推算。
物理做到"趋势对、数量级对"，每个结论都标明是**公认结论**还是**估计参数**（和涵道无人机 README 一样）。

## 总览

| 阶段 | 做什么 | 主要产出 | 预计 |
|---|---|---|---|
| 0 | 定规格 | `docs/规格.md` | 半天 |
| 1 | Blender 建模 | `build_etcher.py`、腔体 glb（完整 + 剖切）、平台 glb、`parts.json`、预览图 | 1–2 天 |
| 2 | 网页 · 结构查看器 | 离线版 html、claude.ai 网页版 | 1 天 |
| 3 | 网页 · 原理实验 | `sim/*.js` + 9 个实验 | 3–5 天 |
| 4 | 网页 · 操作台 | 配方、时序、联锁、故障、考核模式 | 2–4 天 |
| 5 | VR | VRToyBox 导入；网页 WebXR；可选 UE 交互 | 1 天起 |
| 6 | 扩展（可选） | CCP 介质腔、3D NAND 低温刻蚀、和 FabSim3D 联动 | 按需 |

每个阶段结束你看一遍（截图或网页），确认后再进下一阶段。
阶段 1、2 做完（2–3 天）就有能看、能拆的东西；阶段 3 是学原理的核心；全部做完大约 2–3 周，看你审阅的节奏。

## 阶段 0 · 定规格（半天）

先把"建什么、多大、参数什么范围"写进 `docs/规格.md`，后面建模和仿真都照这份来。

### 默认选择（你不改就按这个）

| 项 | 默认 | 理由 |
|---|---|---|
| 腔型 | ICP 导体刻蚀：平面线圈 + 陶瓷介质窗 + 静电卡盘 | 源功率和偏压分开，原理最好讲；刻多晶硅和硅，能接上 FabSim3D 的栅极和 STI |
| 晶圆 | 300 mm | 现在的主流 |
| 平台 | 3 个装载口、前端机械手、对准器、2 个负载锁、六边形真空传输腔、4 个工艺腔 | 常见配置 |
| 精细度 | 腔体细做（约 120 件），平台粗做（约 40 件） | 学原理主要看腔体 |

### 规格.md 写什么

1. **零件清单**：名字、子系统、材料、作用、是不是消耗件、拆机顺序。初稿：
   - **源**：平面线圈（内外两组）、线圈支架、法拉第屏蔽、陶瓷介质窗、中心进气喷嘴、窗口冷却风道、源匹配器（两个真空可变电容 + 电感）、RF 屏蔽罩
   - **腔体**：铝腔体（内壁耐等离子体涂层）、内衬、等离子体约束环、传片口 + 闸阀、观察窗 + OES 光纤、两个电容薄膜真空计、腔壁加热
   - **卡盘**：静电卡盘（陶瓷顶层、吸附电极、多区加热器、带冷却液流道的底座、背氦槽）、3 根升降针 + 波纹管 + 驱动、边缘环 + 边缘环升降针、绝缘环、偏压匹配器、冷却液管和氦气管、高压接线
   - **排气**：摆阀、磁悬浮分子泵、前级管道（干泵和尾气处理在楼下，只画接口）
   - **气路**：气体盒（质量流量计、气动阀、过滤器）、管路
   - **平台**：装载口、前端机械手、对准器、风机过滤单元、负载锁、双臂真空机械手、闸阀、机架和电源柜
2. **尺寸**（估计值，建模前再对照专利图核一遍）：腔体内径约 500–600 mm；晶圆到介质窗约 100–150 mm；边缘环外径约 350–380 mm。
3. **参数范围**（估计参数，仿真和配方都用这一套）：
   - 压力 1–100 mTorr
   - 源功率 0–3000 W，13.56 MHz
   - 偏压功率 0–1000 W，13.56 MHz 或 2 MHz，可脉冲
   - 气体 Cl₂ / HBr / O₂ / Ar / CF₄ / SF₆，各 0–500 sccm
   - 卡盘温度约 −20–120 °C，背氦 5–30 Torr
4. **参考资料**：见文末。

**你要做的**：看一遍清单，删掉不想要的、加上想看的。

## 阶段 1 · Blender 建模（1–2 天）

照万用表、车床、AI 服务器的做法：`build_etcher.py` 用代码生成全部零件，几秒钟出结果。

### 步骤

1. **骨架**：单位米，+Z 向上，腔体轴线就是 Z 轴，晶圆上表面在 Z = 0。所有零件挂在空物体 `Chamber` / `Cluster` 下，命名 `P01_…`。材质金属度都压在 0.55 以下（VRToyBox 没有反射探针）。
2. **旋转体用"截面 + 旋转"生成**：腔体、介质窗、卡盘、边缘环、内衬、分子泵大多是旋转体。写一个函数，输入截面折线和旋转角度：
   - 360° = 完整件
   - 270° = 切掉一个象限的剖切件，端面补上，涂"剖面色"（像机械图的剖面线）

   同一份代码出两个版本，剖开就能看到壁厚、流道和内部结构。
3. **卡盘内部做真结构**：陶瓷层里的双极吸附电极、同心的加热分区（4 区）、底座里的冷却液螺旋流道、背氦沟槽和孔。剖切时都看得见。
4. **源组件**：平面螺旋线圈（内外两组）、匹配器盒里的两个真空可变电容和电感、RF 电缆接到线圈。
5. **平台**：低细节，单独一个 glb。
6. **零件信息（glb extras）**：沿用 VRToyBox 的约定 `part_no / name_cn / material_spec / desc / ex`，另加 `group`（子系统）和 `consumable`（是否消耗件）。`desc` 写"它在刻蚀里干什么"，不只写名字。
7. **动画**（.blend 时间线，同时导出 `motion.json` 给网页用）：
   - **拆机**：按真实开腔保养的顺序。掀起源组件（线圈 + 匹配器）→ 取介质窗 → 取内衬 → 取约束环 → 取边缘环 → 拔升降针……卡盘底座和腔体不动。各零件出场时刻错开，因为 VRToyBox 会把路线相同的零件合成一个抓取单元。
   - **爆炸后的摆法**：吸取万用表的经验，不竖着往上摞（会挡住卡盘）。源组件往后上方，卡盘叠层往侧面摆开。
   - **传片**：前端机械手从装载口取片 → 对准 → 进负载锁抽真空 → 真空机械手送进工艺腔 → 闸阀开、关 → 升降针接片、下降。
8. **输出**：`output\etcher.blend`、`etch_chamber.glb`、`etch_chamber_cut.glb`、`cluster.glb`、`parts.json`，以及 Cycles 预览图 4 张（装配、剖切、爆炸、平台）。
9. **启动.bat**：找 Blender（`blender_path.txt` → PATH → Program Files → Steam）→ 后台跑脚本 → 菜单：打开网页 / 用 Blender 打开 / 渲染预览。

### 验收

- Blender 里按空格能播拆机和传片动画
- 每个零件都有中文名和作用
- 你看预览图提比例和外观意见，改一轮

**你能学到**：一台刻蚀机由哪几部分组成，每个零件干什么，哪些会被等离子体吃掉、要定期换。

## 阶段 3 · 网页 · 原理实验（3–5 天）

核心阶段。仿真写成 `sim/` 下的纯 JS 模块，每个模块都有 node 单元测试。
界面每个实验一页：左边是 3D 腔体（辉光、鞘层、离子），右边是曲线或剖面，底下是滑杆。

每个实验都是同一个形式：**先问一个问题让你猜 → 拉滑杆看结果 → 字幕解释为什么**。

### 3.1 仿真模块（从简单到复杂）

| 模块 | 算什么 | 用的模型 | 可信度 |
|---|---|---|---|
| `vacuum.js` | 平均自由程、帕邢曲线 | λ = kT / (√2·π·d²·p)；帕邢定律 V = B·pd / ln(A·pd / ln(1+1/γ)) | 公认结论 |
| `plasma0d.js` | 电子密度 nₑ、电子温度 Tₑ、离子通量 | 整体模型（Lieberman 教材）：粒子平衡决定 Tₑ（在这个模型的假设下只和气压、腔体尺寸有关），功率平衡决定 nₑ（和吸收功率成正比）；Bohm 速度 u_B = √(eTₑ/M)，离子通量 Γᵢ = n·u_B。**加 E–H 模式**：低功率是电容耦合（E 模式，密度低、暗），超过阈值跳到感应耦合（H 模式），降功率时在更低的功率才跳回（迟滞）。**CCP 模式**：功率平衡里加"离子在鞘层里带走的能量"这一项，ICP 和 CCP 的密度差要由它算出来，不能直接写死 | 公认模型，截面数据先用 Ar；E–H 阈值是估计 |
| `radicals.js` | 自由基通量 Γₙ（Cl、F、O 原子） | 给 `surface.js` 供 Γₙ，补上"Cl₂ 被打碎成多少 Cl"这一环。**先做 A**：解离率当滑杆，Γₙ 由流量、功率和解离率估算。**以后可换 B**：照 Lee & Lieberman 1995 的 Cl₂ 整体模型（含解离、负离子）。Cl₂ 是电负性气体，离子成分和能量损失都和 Ar 不同，直接套 Ar 会让 nₑ 和 Γᵢ 偏 | A 是估计参数；B 是公认模型 |
| `sheath.js` | 鞘层厚度、离子能量和能量分布 | Child 定律；平均离子能量 ≈ 偏压功率 ÷ 离子电流（近似）；能量分布的双峰宽度由离子穿过鞘层的时间和 RF 周期之比决定（Kawamura 等 1999）。**偏压控制方式开关**：按功率（离子能量随源功率变）/ 按电压（离子能量基本不随源功率变） | 公认趋势，系数是估计；真实机台用哪种控制方式未核实 |
| `surface.js` | 刻蚀速率、选择比 | 表面覆盖率模型：自由基吸附占位，离子轰击把产物打走，ER = 1 / (1/(s·Γₙ) + 1/(Y·Γᵢ))，再加自发化学刻蚀项；产额 Y ∝ √E − √E_th | 公认模型，参数估计 |
| `profile2d.js` | 二维剖面演化 | 元胞 + 蒙特卡洛：网格上发射离子（角分布来自鞘层模型）和自由基（余弦分布，按黏附系数反弹）；掩膜按选择比被侵蚀；钝化层沉积在侧壁，被离子从底部打掉 | 定性 |
| `uniformity.js` | 整片晶圆的刻蚀速率分布 | 径向密度分布（圆柱扩散的 J₀ 形状，叠加内外线圈功率比）+ 卡盘分区温度对化学项的影响 + 边缘环高度对边缘离子入射角的影响 | 定性 |
| `oes.js` | 光谱终点曲线 | 产物谱线强度 ∝ 产物生成率，膜刻穿时下降；加噪声，用一阶导数判终点 | 定性 |

### 3.2 实验清单

1. **为什么要抽真空**：拉气压，平均自由程从约 70 nm（大气压）变成几毫米（10 mTorr）。帕邢曲线为什么有最低点。
2. **等离子体怎么点着**：源功率从 0 慢慢加，先是暗淡的 E 模式，过了阈值突然跳亮成 H 模式，密度跳一到两个数量级；再往回降，要降到更低的功率才跳回去（迟滞）。H 模式下源功率 ↑ → 密度 ↑（成正比）；气压 ↑ → 电子温度 ↓。腔里的辉光亮度跟着变。
3. **ICP 和 CCP**：同样功率下 ICP 密度高一到两个数量级（由 CCP 的鞘层能量损失算出来）；CCP 的密度和离子能量绑在一起调；ICP 只有偏压**按电压控制**时才能真正分开调，按功率控制时还是耦合的（见实验 4）。
4. **鞘层和离子能量**：偏压功率 ↑ → 离子能量 ↑；偏压不变、源功率 ↑ → 离子能量反而 ↓（离子电流变大了）；切到"按电压控制"再做一遍，看离子能量不再跟着源功率变；偏压频率低 → 能量分布的双峰拉宽。
5. **离子 + 自由基远大于各自之和**：只开离子 / 只开自由基 / 一起开（Coburn–Winters 实验）。氯刻硅为什么是各向异性、氟刻硅为什么是各向同性。
6. **剖面**：各向同性钻蚀 → 加偏压变直 → 加 O₂ / HBr 侧壁钝化；看弓形、微沟槽、掩膜削角怎么出来；窄沟比宽沟刻得慢（ARDE）；图形密的地方刻得慢（负载效应）。
7. **均匀性**：调内外线圈功率比、卡盘分区温度、边缘环高度，看刻蚀速率图从"中间快"变成"边缘快"；边缘环磨低以后，边缘的鞘层弯下去，孔会歪。
8. **终点检测**：谱线在刻穿时下降，算法判出终点；过刻不够会留残留，过刻太多会伤到下层。
9. **前沿（可选）**：Bosch 交替刻蚀出的扇贝纹；原子层刻蚀"改性 → 去除"的自限制循环；低温刻蚀让侧壁更直。

### 3.3 可信度怎么保证

- 每个数字都标"公认结论 / 估计参数"
- 单元测试查极限情况（只有离子时速率很低；H 模式下功率翻倍密度翻倍；E–H 跳变有迟滞）和量级（ICP 密度 10¹¹–10¹² cm⁻³，CCP 10⁹–10¹⁰ cm⁻³，Tₑ 2–5 eV）
- 测试分两类标清楚：**模型自洽检查**（例如"气压不变时 Tₑ 不随功率变"，这是整体模型的假设；真实腔里有气体加热、分步电离，Tₑ 会小幅变化）和**对照公开数据的量级检查**。前者通过不代表和现实一致
- 可选：用 ViennaPS（`pip install ViennaPS`）离线算几组配方的剖面，存进 `data/viennaps/`，网页里叠加对比"简化模型 vs ViennaPS"

### 3.4 技术要点

- 剖面仿真放进 Web Worker，不卡界面；网格电脑 512×384，手机降一半
- 辉光：腔内一个半透明体积着色器，颜色按气体，亮度按 nₑ；鞘层画成晶圆上方的一层暗区，离子画成往下的短线
- `make_template.mjs` 改成把 `sim/` 一起打包进离线版

**你能学到**：为什么要真空；等离子体怎么产生；鞘层为什么让离子垂直打下来；为什么用两个频率分别控制密度和能量；为什么刻硅用氯、刻氧化硅用碳氟气体；选择比、各向异性、侧壁钝化从哪来；常见剖面缺陷的成因；均匀性怎么调；终点怎么判。

## 阶段 4 · 网页 · 操作台（2–4 天）

把原理实验串成"真开一台机器"。比湿法槽简化：不做软 PLC 和梯形图，用一个 JS 状态机（`sim/tool.js`）。

1. **一片晶圆的完整时序**：负载锁抽真空 → 传片进腔 → 关闸阀 → 卡盘吸附 → 建立背氦、查漏率 → 进气，摆阀把压力稳到设定值 → 起辉（先进 E 模式，跳到 H 模式时负载阻抗突变，匹配器重新调谐，反射功率降下来）→ 加偏压主刻 → 终点 → 过刻 → 关 RF → 去吸附（释放残余电荷）→ 升针 → 传出 → 无片自动清洁
2. **配方编辑器**：多步表格，每步设时间或终点、压力、源功率、偏压、各路气体、卡盘各区温度、背氦压力。预置配方：
   - 多晶硅栅刻蚀：破自然氧化层 → 主刻 → 过刻
   - STI 浅槽刻蚀：和 FabSim3D 里的那一步对应
3. **趋势图**：压力、正向和反射功率、OES、卡盘温度、背氦流量
4. **联锁**：闸阀没关不能起辉、背氦漏率超限不能加 RF、压力不在范围不能起辉……按钮锁住并写明原因（照湿法槽的"为什么按钮锁了"）
5. **故障注入和报警**：

   | 故障 | 能看到的现象 |
   |---|---|
   | 边缘环到寿命（按 RF 小时算） | 边缘刻蚀速率和孔的角度漂移 |
   | 背氦泄漏 | 晶圆温度升高，速率和选择比跟着变 |
   | 匹配器失调 | 反射功率高，等离子体不稳 |
   | 质量流量计漂移 | 刻蚀速率慢慢漂 |
   | 摆阀卡住 | 压力控不住 |
   | 腔壁聚合物积累 | 速率逐片漂移、颗粒增多（引出陈化和湿法清洁） |
   | 真空泄漏 | 升压率测试不合格 |

6. **考核模式**：随机注入一个故障，你看趋势图和剖面判断是什么问题，答完给解释。

**你能学到**：机器是怎么一步步把一片晶圆刻完的；配方里每个参数改了会怎样；常见故障怎么从数据里看出来。

## 阶段 5 · VR（1 天起）

### 5a 结构进 VRToyBox（约 1 天，先做）

走现有流程：

1. 用阶段 1 的剖切版 glb，在 `Tools/import_model.py` 的 `MODELS` 里加一项（`length_cm` 建议 60）
2. `EToyModelKind` 加 `Etcher`，加安装点和触屏按钮（现在已有 9 个模型，触屏可能要重新排）
3. 跑 `toy.GrabAudit Etcher quit`，检查抓取单元数和总览图；从前方约 50° 俯视检查爆炸摆法
4. 注意：金属度 ≤ 0.55；路线相同的零件会被合成一个抓取单元，出场时刻要错开

### 5b 网页直接进 VR（约 1 天，推荐第二步）

给阶段 2–4 的网页加 three.js 的 WebXR 按钮，在 Quest 浏览器里打开就能进 VR，原理实验不用重写。用手柄射线点零件、拉滑杆。

### 5c UE 里做交互（3–5 天，可选）

只有想在 VRToyBox 里也能做实验时才做：闸阀、升降针、传片动画；辉光材质（颜色按气体）；触屏上选预置配方 → 播放阶段 3 预先算好的剖面序列。

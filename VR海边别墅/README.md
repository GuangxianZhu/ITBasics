# VR 海边别墅（Blender 建模 → Quest 3）

用脚本自动生成一栋海边二层小别墅，有两种看法：

| | `启动_Godot版.bat`（推荐） | `启动.bat`（Blender 版） |
|---|---|---|
| 能做什么 | 走路（撞墙、上楼梯）、瞬移、推拉门、开关灯、白天/黄昏/夜晚，海面和泳池有波光 | 只能看，在点位间瞬移 |
| 需要 | Blender（导出模型）+ Godot（bat 第一次运行时自动下载，约 70MB） | Blender |

两个版本的模型来自同一个脚本 `build_villa.py`。改尺寸只要改这一处，两边都会跟着变。

---

## Godot 版（可交互）

![Godot 版预览](godot_preview.jpg)

### 用法
1. Quest 3 打开 **Virtual Desktop** 连上电脑，VD Streamer 设置里把 **OpenXR Runtime** 设成 **VDXR**
2. 双击 `启动_Godot版.bat`，它会依次：`git pull` → 用 Blender 导出 `godot/model/villa.glb` → 找到 Godot（找不到就从 GitHub 官方下载 4.7.2 放进 `tools/`）→ 运行
3. 没戴头显时会自动进入**桌面模式**，用键鼠操作，方便先在屏幕上看看

### 操作
| VR 手柄 | 桌面（键鼠） | 作用 |
|---|---|---|
| 左摇杆 | WASD / 方向键 | 走路（朝你看的方向） |
| 左手握把按住 | Shift | 走快 |
| 右摇杆左右 | 鼠标 | 转身（VR 里每次转 30°，不容易晕） |
| 食指搭在扳机上 → 出现激光；按下扳机 | 准星 + 左键 | 指地面 = **瞬移**；指门 = **推拉门**；指墙上的白色小面板 = **开关灯** |
| A / X | T | 下午 → 黄昏 → 夜晚 |
| B / Y | Tab，或 1~6 | 去下一个参观点位 |

激光颜色：绿色 = 可以瞬移，黄色 = 可以操作，蓝色 = 不能。

可推拉的门：一楼海景窗**正中间两扇**、二楼海景窗**最右一扇**（通阳台）。灯开关：一楼在厨房边的墙上，二楼在楼梯口。

### 原理
- **Blender 是"模型工厂"**：`export_godot.py` 先调用 `build_villa.py` 生成场景，再加上 Godot 需要的部件（拆分出来的门扇、开关、楼梯隐形坡道、灯位），最后导出 glb
- **Godot 运行时加载 glb**（GLTFDocument），不走编辑器导入，所以"重新生成 → 直接运行"中间没有额外步骤
- **碰撞**：每个物体自动生成三角网格碰撞体；海、树叶、远山不加。人用的是胶囊体（半径 22cm）
- **楼梯**：真实踏步只做显示，下面垫了一块看不见的 34° 斜坡，走起来很顺；台基、门槛这类 ≤36cm 的坎，靠"抬脚检测"迈上去
- **房间尺度**：你在现实里走动时，碰撞体会跟着头移动，所以墙能挡住你。但现实中的墙挡不住你的头：如果你真的往墙里探头，还是能"穿墙"看到外面，这是所有 VR 游戏的共同限制
- **水面**：平面不动，只让两层法线贴图朝不同方向滚动，反光就会动起来。这种做法开销几乎为零
- **高度**：VR 里用的是你**真实的头高**（OpenXR Stage 空间，原点在地板）

### 已测 / 未测
- ✅ 在 Godot 4.7.2 上实际运行过（Linux，软件渲染）：模型加载、材质、三个时间段，截图如上
- ✅ 自动走路测试（`godot --path godot -- --walktest`）：上楼梯到 3.5m、关着的门挡住人、开门后能走出去、从沙滩迈回 30cm 的台基、二楼阳台被栏杆挡住，全部通过
- ❌ **没在真头显上测过**：手柄按键名、Virtual Desktop 下的手柄映射、帧率，都需要你实际戴上确认
- 推测：Quest 3 走 Virtual Desktop 时，Godot 默认的手柄映射（Oculus Touch）应该能用，但没有实测

### 可能失效的地方
| 现象 | 处理 |
|---|---|
| 一启动就是桌面模式 | 头显没连上 VD，或者 OpenXR 运行时不是 VDXR。也可以试试 SteamVR，把它设为默认的 OpenXR 运行时 |
| 按键没反应 / 键位不对 | 第一次运行时 Godot 会自动生成默认手柄映射；如果 VDXR 报告的手柄类型不同，就需要改映射。把现象告诉我 |
| VR 里卡顿 | 帧率要稳定在头显刷新率（72/90/120）。可以在 `main.gd` 里关掉太阳阴影（`sun.shadow_enabled = false`）或雾效 |
| 第一次启动很慢 | Godot 在编译着色器，第二次会快很多 |
| bat 下载 Godot 失败 | 手动从 godotengine.org 下载 Godot 4，把 exe 的完整路径写进 `godot_path.txt` |

## Blender 版（只看）

![Blender 版预览](preview.jpg)

1. 同样先用 Virtual Desktop 连上电脑，运行时设为 VDXR
2. 双击 `启动.bat`
3. Blender 右侧边栏（按 `N`）→ **VR** 标签 → **Start VR Session**；Landmarks 列表里点选点位后点激活，就能瞬移

> ⚠ 每次运行 `启动.bat` 都会**重新生成并覆盖** `villa.blend`。手动改过的话请另存为其他文件名。

## 场景参数（`build_villa.py` 开头）
- 1 单位 = 1 米；Blender 里 **+Y 是大海**（导出到 Godot 后变成 -Z）
- 一楼地面 0.3m（台基），二楼地面 3.5m，层高 3.2m；楼梯 18 级，每级 17.8cm，踏面 28cm；栏杆 1.1m
- 全场景约 2600 个面，非常轻

## 文件
| 文件 | 作用 |
|---|---|
| `build_villa.py` | 生成别墅（Blender） |
| `export_godot.py` | 在上面的基础上加交互部件，导出 glb 给 Godot |
| `vr_setup.py` | Blender 版打开时启用 VR 插件、设置视口 |
| `godot/main.gd` | Godot：加载模型、碰撞、材质、灯光、时间段、门和开关 |
| `godot/player.gd` | Godot：VR 玩家 + 桌面模式、移动、瞬移、激光 |
| `godot/water.gdshader` | 海面、泳池的波光着色器 |

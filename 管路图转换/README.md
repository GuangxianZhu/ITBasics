# 管路图转换（フローシート → 表格 → draw.io）

把フローシート整理成 **部品表 + 连接表**，再自动生成 draw.io 图。
表格才是核心资产：AI、统一查询器都能直接用；draw.io 只是它的可视化。

## 准备
```
pip install pdfplumber
```
（table_to_drawio.py 只用 Python 标准库）

## 流程

### 1. 控制对象表 PDF → 部品表
```
python pdf_table_to_csv.py 控制对象表.pdf
python pdf_table_to_csv.py 控制对象表.pdf --pages 3-8     # 只处理部分页
python pdf_table_to_csv.py 控制对象表.pdf --no-lines      # 表格没有格线时
```
输出 `<PDF名>_tables/tables_main.csv`（跨页合并，去掉重复表头）。
在 Excel 里打开，整理成 `部品表.csv`：

| 位号 | 种类 | 说明 |
|---|---|---|
| AV-12 | 气动阀 | 2号槽 DIW入口 |

先确认 PDF 是文字版（文字能用鼠标选中）。扫描件提取不了。

### 2. 让 Copilot 出连接表
给 Copilot：部品表 + 凡例 + フローシート分区截图（区域间留重叠，截断处手写去向）。
提示词模板：

```
添付のフローシート（一部）と部品表をもとに、配管の接続関係を CSV で出力してください。

ルール:
- 列は「接続元,接続先,配管」の3列のみ
- 位号は必ず部品表に存在するものを使う。部品表に無いものは位号の前に「?」を付ける
- 流れの向きは上流→下流。向きが分からない場合は「配管」列の末尾に「(向き不明)」
- ヘッダー（総管）からの分岐は、ヘッダーを接続元として1本ずつ書く
- 図の範囲外へ出る配管は、接続先を「範囲外:◯◯」とする（◯◯は図に書かれた行き先）
- 推測した接続は「配管」列の末尾に「(推測)」と付ける
- CSV 以外の説明は不要
```

### 3. 核对连接表
对着原图逐行确认，重点看带 `?`、`(推测)`、`(向き不明)` 的行。存成 `连接表.csv`。

### 4. 生成 draw.io
```
python table_to_drawio.py 部品表.csv 连接表.csv -o ONB供给.drawio
```
- 按流向从左到右自动分列，总管画成长条
- 按位号/种类自动选形状：阀=菱形，泵=圆，传感器=小圆，槽=大框，过滤器=六边形
- 不同管线种类用不同颜色
- **红色虚线** = 连接表里有、部品表里没有 → 要补
- **灰色（最右列）** = 部品表里有、没有任何连接 → 漏连？
- 每个图形带 tag/type/desc 属性（右键 → Edit Data）

CSV 列名中日英都能认（位号/タグ/tag，从/接続元/from …），UTF-8 和 Excel 的 Shift_JIS 都能读。

`示例/` 里有一组样例可以先跑一下：
```
python table_to_drawio.py 示例/部品表.csv 示例/连接表.csv
```

## 注意
公司的フローシート和控制对象表只在公司内部处理（Python / 公司 Copilot），不要提交到本仓库、不要发给外部 AI。

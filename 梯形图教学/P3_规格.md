## 2. Controller 接水槽（冻结，扩展 P2 的接口）

```python
class Controller:
    def __init__(self, program, scan_ms=10, tank=None): ...   # tank 为 None 时新建 Tank()
    tank: Tank
    sim_time: float          # 仿真经过的秒数 = 完成的扫描轮数 × scan_ms/1000（load 时归零）
    def load(self, program): ...   # 在 P2 基础上：tank 换成新的 Tank()（水位归零），sim_time=0
    def reset_tank(self): ...      # tank 换成新的 Tank()，PLC 和程序不动
```

联动顺序必须和 `Runner.tick()` 完全一致：

- **每一轮扫描开始前**（即要 yield `input` 之前、新建 `plc.steps()` 生成器时）：
  `tank.sensors()` 的 X2、X3 写进 `plc.set_input`。按钮 X0/X1 仍由 `set_button` 随时写入。
- **每一轮扫描的 `output` 步完成后**：`tank.step(scan_ms/1000, plc.output("Y0"), plc.output("Y1"))`，`sim_time += scan_ms/1000`。
- `set_button("X2"/"X3", …)` 写进去也会在下一轮开始前被水槽传感器覆盖（P3 起 X2/X3 只由水槽决定）。

后果（这是故意的，教学上正好说明"仿真时间"）：暂停时水位不动；慢放时水位也跟着慢；单步时只有走到"输出刷新"那一步水位才变。

**验证方法**：同一个程序、同样的按钮操作，`Controller.update()` 和 `Runner.run()` 跑同样的时间，水位必须相同（测试里有）。

## 4. 3D 水槽场景（ui/）

### 4.1 布局

把 P2 右侧"输入"区（x2/x3 切换按钮那块）换掉：

```
┌──────────────────────────────┬─────────────────────┐
│ 示例: [自保持][定时器]…[满水后排水] │                     │
├──────────────────────────────┤   3D 水槽视图          │
│        梯形图区                │  （独立 DisplayRegion  │
│                              │    + 独立相机）         │
├──────────────┬───────────────┤                     │
│ 指令表         │ 监视           │  水位 63.2%  [重置水槽] │
│              │               │  [X0 启动] [X1 停止]   │
├──────────────┴───────────────┴─────────────────────┤
│ 控制栏（同 P2）                                        │
└────────────────────────────────────────────────────┘
```

- 3D 视图用 `base.win.makeDisplayRegion(0.68, 1.0, 0.33, 0.97)` + 新建一个 `Camera`，场景挂在独立的根节点（不要挂 `render` 上和别的东西混）。背景色与 2D 一致或略深。
- 示例按钮一行放不下 6 个时，缩小按钮或分两行，不得重叠。
- 示例按钮的当前选中项要有区别（底色不同）。

### 4.2 场景内容（全部程序生成，不用外部模型文件）

在 `ui/geom.py` 里写生成长方体/圆柱的小函数（`GeomVertexData` + `GeomTriangles`），其他文件调用它。

| 物体 | 表现 | 跟谁走 |
|------|------|--------|
| 槽体 | 半透明（alpha≈0.25）的立方体或圆柱，有轮廓线 | 固定 |
| 水 | 蓝色半透明立体，**高度 = level%**（底部固定，按 z 缩放） | `tank.level` |
| 上限开关 X3 | 槽壁 80% 高度处的小方块 + 文字 "X3 上限" | ON 绿 / OFF 灰（读 `plc.get("X3")`） |
| 下限开关 X2 | 槽壁 20% 高度处，同上 | `plc.get("X2")` |
| 给水管 + 阀 Y0 | 槽顶上方的管子，阀门小方块；**阀开时有一道下落水柱**（细长蓝色立体，从管口到水面） | `plc.output("Y0")` |
| 排水管 + 阀 Y1 | 槽底侧面的管子，阀门小方块；阀开时管口有水流出 | `plc.output("Y1")` |
| 完成灯 Y2 | 槽旁边的小球/小方块，ON 时亮黄色 | `plc.output("Y2")` |
| 溢出 | `tank.overflow` 为真时槽体轮廓闪红（0.5 秒周期） | `tank.overflow` |

注意：
- 场景只读状态、不改状态。**颜色/高度判断写在 `app/` 里的一个纯函数**，ui 只照着设：

```python
# app/scene_state.py（冻结）
def scene_state(ctrl) -> dict:
    return {
        "level": float,            # 0~100
        "inlet_open": bool,        # plc.output("Y0")
        "drain_open": bool,        # plc.output("Y1")
        "lamp_on": bool,           # plc.output("Y2")
        "x2_on": bool,             # plc.get("X2")
        "x3_on": bool,             # plc.get("X3")
        "overflow": bool,          # tank.overflow
        "level_text": str,         # "水位 63.2%"（保留 1 位小数）
    }
```

- 透明物体：`setTransparency(TransparencyAttrib.MAlpha)`，水和槽体放 `fixed` bin 控制先后，或 `setDepthWrite(False)`，保证水在槽里看得见。
- 相机固定斜上方 3/4 视角，整个槽和管子都在画面内。可选：鼠标在 3D 视图里拖动旋转（不做也行）。
- 每帧只改已有节点的 scale / color / show / hide，**不要每帧新建几何体**。

### 4.3 按钮

- 3D 视图下方：`水位 xx.x%` 文字、`[重置水槽]`（调用 `ctrl.reset_tank()`）、`[X0 启动]` `[X1 停止]`（瞬时，同 P2）。
- X2/X3 的切换按钮删除。键盘 `0`/`1` 保留。
- **按住按钮后把鼠标拖出按钮再松开，X0/X1 必须回到 OFF**（P2 未验证的点）。做法提示：除了按钮自身的 `B1RELEASE`，再全局 `accept("mouse1-up", …)` 把 X0、X1 都置 OFF。

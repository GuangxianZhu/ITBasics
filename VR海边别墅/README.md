# VR 海边别墅（Blender + Quest 3）

用脚本自动生成一栋海边二层小别墅，在 Blender 里用 Quest 3 走进去看。不需要手动建模。

![预览](preview.jpg)

（预览图是用 Cycles 渲染的，VR 里用的是 Eevee 实时渲染，室内会稍暗一些、反射也会少一些）

## 用法

1. 在 Quest 3 里打开 **Virtual Desktop**，连上电脑。电脑端 VD Streamer 设置里，把 **OpenXR Runtime** 设成 **VDXR**
2. 双击 `启动.bat`，它会依次做这几件事：
   `git pull` 拉取 main 上的更新 → 找到 Blender → 生成 `villa.blend` → 打开它，同时自动启用 VR 插件
3. Blender 右侧边栏（按 `N`）→ **VR** 标签 → **Start VR Session**
4. 同一个标签里的 **Landmarks** 列表就是 6 个点位，点一下就能瞬移过去：

| 点位 | 位置 |
|---|---|
| 01_客厅看海 | 一楼，整面落地玻璃前 |
| 02_泳池边回望 | 泳池角落，回头看房子 |
| 03_二楼阳台 | L 形大阳台 |
| 04_卧室床边 | 二楼卧室 |
| 05_楼梯口 | 一楼楼梯下 |
| 06_沙滩回望 | 海边，看整栋房子 |

如果没找到 Blender：在 bat 旁边新建 `blender_path.txt`，写入 blender.exe 的完整路径。

> ⚠ 每次运行 bat 都会**重新生成并覆盖** `villa.blend`。如果在 Blender 里手动改了东西，请另存为其他文件名。

## 场景参数（都在 `build_villa.py` 开头）

- 1 个单位 = 1 米，**+Y 方向是大海**
- 一楼地面 0.3m（台基），二楼地面 3.5m，层高 3.2m
- 楼梯 18 级，每级 17.8cm，踏面 28cm（常见住宅尺寸，VR 里走起来不会觉得怪）
- 栏杆 1.1m，门高 2.1–2.3m
- 全场景约 2600 个面，非常轻。显卡压力主要来自 Eevee 的阴影和玻璃透明

## 原理和假设

- **为什么用脚本生成，而不是手工建模**：所有尺寸都是参数，想改层高、窗宽，改一个数字重跑就行；在 VR 里看到比例不对，也能快速迭代
- **为什么墙不用布尔运算挖洞**：墙直接按"窗间墙 + 窗下墙 + 窗上墙"拆成几个长方体，网格干净，渲染便宜，任何 Blender 版本都能用
- **为什么海面是平面**：真实波浪的 Ocean 修改器每帧都要在 CPU 上重新生成网格，VR 必须稳定在 72–90fps，所以用"平面 + 程序凹凸"来模拟波光
- **VR 点位的高度**：相机放在"地面 + 1.65m"。VR 插件在默认的非 Absolute Tracking 模式下，会把头显的起始位置对准这个点；如果你勾选了 Absolute Tracking，高度会按房间的实际地面算，这时可能偏高

## 可能失效的地方

| 现象 | 原因 / 处理 |
|---|---|
| Start VR Session 没反应或报错 | 当前生效的 OpenXR 运行时不对，检查 VD 是否设成了 VDXR；也可以改用 SteamVR |
| 手柄不响应 | Blender 的手柄映射不一定兼容 VDXR（推测，未实测），可以换 SteamVR 运行时试试 |
| VR 里卡顿 | VR 标签里把 Shading 从 Rendered 改成 Material 或 Solid |
| 室内太暗 | Eevee 的实时全局光照有限。可以调亮"灯光"集合里的室内灯，或者打开 Eevee 的 Raytracing（Blender 4.2+，比较吃性能） |
| 老版本 Blender（< 3.6）报错 | 没有测试过。脚本只在 Blender 5.2 上实际跑过 |

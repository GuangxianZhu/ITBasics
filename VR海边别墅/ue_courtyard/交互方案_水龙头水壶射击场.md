## 0. 串成一条玩法

香草厨园本来就有 **石水槽 + 龙头**（静态模型）和 4 个种植池，正好串起来：

**拧开龙头 → 水壶接水（水位上涨）→ 走到种植池倒水浇花（土变深色）**

水龙头和水壶共用一套"水"：水流特效 + 容器里的水量变量 + 被浇的表面变湿。
射击场是另一套独立玩法（见第 3 节）。（之前写的"铲子"是语音识别错误，原意是射击场。）

## 1. 水龙头（最简单，建议第一个做）

- 手柄不是"抓起来"，而是"抓住后绕轴转"：VR 模板 `GrabComponent` 的抓取类型设 **Custom**，只收"被抓/松开"事件，自己算角度。✅ 主流做法
- 角度算法：把手的位置投影到龙头转轴的垂直平面上，算和起始方向的夹角，限制在 0–90°。不用物理约束（Physics Constraint 在 VR 里容易抖）。✅
- 开度 0–1 → 控制 Niagara 水流的生成速率和粗细、流水声音量。
- 下面放一个 Box 碰撞当"接水区"：水壶口在里面就加水。

## 2. 水壶（核心难点：什么时候出水）

- 判断出水：**壶嘴口的世界高度 低于 壶内水面高度** 时才出水（水面始终水平）。所以水越少，要倾得越斜才出水。✅ 物理上成立；💭 实现上用"水量→水面高度"查表近似即可
- 出水速率 ∝ 高度差（可以用 √高度差，近似托里拆利定律）。
- 水流：Niagara 粒子带重力 + 碰撞事件；落到种植池（带 Tag）就让土的材质参数"湿度"上升。
- 壶内水面：壶内一个平面网格，材质用世界坐标保持水平；或者只做外观不可见（壶不透明时最省事）。
- 不用 Niagara Fluids（真流体）：⚠️ 太重，VR 90 帧（forward 渲染）预算撑不住。

## 3. 射击场（新增，量最大）

### 3.1 要做的东西
| 类别 | 内容 |
|---|---|
| 枪 | 先 1 把手枪，后续可加步枪（双手握） |
| 弹药 | 弹匣（可拔出/插入）、散装子弹（可选：一颗颗压进弹匣）、弹药盒 |
| 机械动作 | 扳机、拉套筒上膛、空仓挂机、退弹匣按钮 |
| 反馈 | 枪口火光、抛壳（弹壳落地有声）、后坐、手柄震动、枪声（室内/室外混响不同） |
| 靶 | 纸靶（弹孔贴花 + 计分环）、钢板靶（被打倒/叮一声）、移动靶（轨道往返） |
| 场地 | 靶道、射击台、隔板、计分屏（命中数/环数/用时）、重置按钮 |

### 3.2 原理和做法
- **子弹用射线（hitscan），不用真的飞的物体** ✅ 主流：手枪弹约 350 m/s，25 m 靶道飞行 0.07 秒，人感觉不到；射线最省、不会穿模。只有远距离要做下坠/飞行时间才用抛射物。
- **后坐**：现实手不会被推开，所以只让枪模型相对手柄偏移一下再弹簧回位 + 手柄震动 ✅ VR 通用做法。不要真推手，会晕/错位。
- **弹匣插入**：枪的弹匣口放一个碰撞区，弹匣进来且方向夹角 < 约 20° 就吸附进去（Snap）。⚠️ 角度阈值要戴头显调。
- **状态机**：空枪 → 插弹匣 → 拉套筒上膛 → 可射击 → 打空后空仓挂机 → 换弹匣 → 按释放。机械状态用一个枚举管，比到处写 if 清楚。
- **数量上限**：弹壳和弹孔贴花用对象池（例如各最多 50 个，超了回收最旧的）💭 防止越打越卡。
- **起点**：UE 的 VR 模板自带一把可抓的手枪和抛射物蓝图（BP_Pistol）⚠️ 需确认工程里还在，可以拿来当起点改造。

### 3.5 弹药系统（参照 Contractors Showdown ExfilZone 的手感）
> 用户要求：子弹是"块"，单颗是一个物件；多颗拿在手里变成一个"组"；单颗或整组都能用手压进弹匣。
> ⚠️ 没查到这款游戏官方的交互说明（wiki 抓不到，视频只有标题），下面是按用户描述 + VR 射击游戏常见做法设计的，细节待用户确认。

- **子弹组 = 一个物件 + 数量**，不是 N 个物理物体 ✅ 常见做法：省性能，抓取只判一个碰撞体。外观最多摆 5 颗扇形排开，再多显示 "×N"。
- **合并**：手里的子弹/组碰到同口径的另一组 → 合成一组。**拆分**：另一只手从组里抓 → 拿走 1 颗。💭
- **压弹**：弹匣顶部（供弹唇）放一个触发区。手里的子弹尖朝前、沿弹匣方向推进去 → 弹匣 +1、手里 −1、震动 + "咔"声。
  - 必须拔出来再推才算下一发（进出区要有"重新上膛"的判定），不然手抖一下会连装好几颗。
- **弹匣是"后进先出"的栈** ✅ 现实如此：最后压进去的那颗最先打出去。混装不同子弹时顺序就有意义。
- **退弹**：手指在弹匣顶部往前推 → 弹出最上面 1 颗。
- **枪膛单独 1 颗**：拉套筒时从弹匣顶取 1 颗进膛；膛里有弹时退弹匣，枪里还剩 1 发。

### 3.3 写实程度（三档，待用户选）
| 档 | 内容 | 工作量 |
|---|---|---|
| 街机 | 抓起来就能打，无限子弹，靶子计分 | 小 |
| 中等 | 弹匣有容量，要拔插换弹、拉一次套筒 | 中（推荐起步） |
| 写实 | 一颗颗压子弹、卡壳、不同口径 | 大（用户选了这条路线：按 Contractors 的弹药系统做） |

### 3.4 模型来源
Fab 免费素材 / 本地 AI 3D 生成（Hunyuan3D）/ 脚本拼几何体。枪的小零件（套筒、弹匣）需要拆成能单独动的部分，AI 生成的整块模型不行，要么找分件素材，要么套筒和弹匣单独做。

## 4. 用蓝图还是 C++

- 现在的远程流程是"蓝图 DSL 逐节点写"，坑多（节点名会变、中文界面接错线）。
- 装好 VS 后可以改成：**C++ 写 3 个组件**（`UFaucetHandle`、`UPourable`、枪械组件 `UGunComponent` / `UMagazine` / `UTarget`），蓝图只负责摆放和调参数。✅ C++ 基类 + 蓝图配置是 UE 主流做法
  - 好处：Claude 远程写文本代码比拼节点稳得多，能 diff、能进仓库。
  - 代价：工程变成 C++ 工程，打开前要先编译；编译失败就打不开（需要保留回退方法）。
- ⚠️ 未验证：UE 5.8 对 VS 2026 的支持情况；已装的 VS 生成工具 2022（17.14）可能也够 UBT 编译。装完后先跑一次空 C++ 类编译测试。

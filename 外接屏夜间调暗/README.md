# 外接屏夜间调暗（Night Dimmer）

晚上自动把外接显示器调暗，开机自动启动。
用显卡 Gamma 斜坡调暗，切窗口、Alt+Tab、开始菜单、UAC 都不会突然变亮。

## 安装
1. 把本文件夹放到固定位置（装好后别再移动）
2. 双击 `安装.bat`（需要已安装 Python）
3. 右下角托盘出现绿色月牙图标即为运行中；之后开机自动启动

## 默认
- 19:00 ～ 07:00 调暗到 50%，前后各 30 分钟渐变
- 只调外接屏（只有一块屏时调这一块）

## 托盘右键菜单
自动 / 一直调暗 / 不调暗、夜间亮度、夜间时段、主屏也调暗、开机自启、退出（恢复亮度）

## 想比 50% 更暗
右键 `解锁更暗(可选).reg` → 合并（需管理员），重启电脑。

## 原理

显卡把画面送往显示器之前，每个像素的颜色值都要先过一张**查找表（Gamma 斜坡）**：R/G/B 各 256 格，正常是"进来多少送出多少"。
本程序把这张表改成"进来的值 × 亮度"（例如 × 0.5）。

```
程序画面 → 系统合成整个桌面 → [Gamma 查找表] → 线缆 → 显示器
                                    ↑ 改的是这里
```

这是最后一道关口，普通窗口、Alt+Tab、开始菜单、UAC 都要经过它，所以不会漏亮
（覆盖半透明窗口的做法压不住系统层级更高的界面，所以切窗口会闪亮）。

- 每 2 秒重写一次表：睡眠唤醒、换分辨率后 Windows 会把表重置
- 截图/录屏看起来是正常亮度（截的是查找表之前的画面）

## 安全性

- **不伤硬件**：不碰背光、不改显示器设置，显示器只是收到偏暗的信号，和播放暗色视频一样
- **不联网，不需要管理员权限**（可选 .reg 除外）
- 对系统的改动只有：
  - 注册表 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 的开机启动项（托盘取消勾选即删除）
  - 本文件夹里的 `settings.json`
  - 安装时从 PyPI 下载 `pystray`、`Pillow`
- 可选 .reg 只是放宽 Windows 对 Gamma 调整幅度的限制。撤销：删除
  `HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion\ICM` 下的 `GdiIcmGammaRange` 后重启

## 风险和副作用

| 情况 | 结果 | 怎么办 |
|---|---|---|
| 程序崩溃或被强制结束 | 屏幕可能停在调暗状态 | 重新运行选"不调暗"，或注销/重启，或拔插一次线 |
| 调得太暗 | 菜单最低 15%，仍看得见 | 托盘切"不调暗" |
| 做过屏幕色彩校准（ICC） | 校准查找表会被覆盖，颜色不准 | 修图调色时先退出程序 |
| 同时开 Windows 夜间模式 / f.lux / 显卡颜色设置 | 互相覆盖，亮度跳动 | 只留一个 |
| 开启 HDR | 可能无效 | 系统限制 |
| 想省电、降低背光 | 做不到：背光不变，暗部对比度下降 | 用显示器自身亮度或 DDC/CI 硬件调光 |

# 日语现场能力 30 天练习计划

目标：解决三个具体问题，而不是笼统地"学日语"。

| 问题 | 现状 | 30 天后的目标 |
|---|---|---|
| ① 洁净室现场听不懂 | 噪音大 + 设备/场景词汇不熟 | 自己负责区域的常用词，听到能马上对上 |
| ② 复杂逻辑说不出来 | 简单的、或指着图能说 | 不看图也能用"结論→理由→手順"讲清一个故障 |
| ③ 沟通慢，担心同事有意见 | 常请对方写进 Teams | 有一套固定说法，请求变得自然、有理由 |

---

## 0. 先守住的规则

- **公司资料只在公司的 Copilot 里处理**（フローシート、制御対象表、报警表、故障记录）。不要贴到外部 AI。
- **在家用外部 AI 练习时，内容要抽象化**：写"纯水槽液位异常"，不写真实机型、客户名、地址、参数值。
- **字幕的用法**：会议中先只听，跟不上再看 Teams 字幕，并把漏掉的词记下来。一直盯字幕会让听力进步变慢。

---

## 1. 每天 20 分钟

| 时段 | 时长 | 做什么 |
|---|---|---|
| 通勤 / 午休 | 10 分钟 | 现场词汇卡（间隔重复） |
| 晚上在家 | 10 分钟 | 口语：讲一个抽象化的故障，AI 纠正后再讲一遍 |

**每周一次**（去洁净室之后）：把没听懂的词和场景记下来，补进词汇卡。

---

## 2. 词汇库怎么建（第 1 周做好，之后持续补）

### 在公司用 Copilot 提取（复制下面的提示词）

```
この資料に出てくる設備・配管・計装・アラーム関連の専門用語を抽出してください。
出力は表形式で、列は次の通り：
用語 / 読み（ひらがな）/ 意味（中国語）/ 現場での使われ方の例文（短く）
重複は除き、使用頻度が高そうな順に並べてください。
```

材料来源（按优先级）：
1. 自己负责区域的フローシート、制御対象表
2. 报警清单（报警名就是现场最常说的话）
3. 过去的故障调查记录、议事录
4. 每周洁净室里没听懂的词（最重要，是真实现场的样本）

### 词汇卡的格式

每张卡只放一个词，正面放**读音**（练的是听），背面放写法和意思：

```
正面：ぎゃくしこうべん
背面：逆止弁 ／ 止回阀 ／ 例：逆止弁が効いてないかも
```

先听音再看字，因为现场是靠耳朵接收的。

### 复习节奏
新卡当天、第 2 天、第 4 天、第 7 天、第 14 天复习。用 Anki，或者日语语感训练器都可以。

---

## 3. 口语练习方法（晚上 10 分钟）

### 模板：結論 → 理由 → 手順

```
結論：〇〇が原因だと考えています。
理由：△△のログで、××のタイミングで□□になっているからです。
手順：まず◇◇を確認して、次に▽▽を試したいと思います。
```

这个顺序本来就是日本职场报告的标准写法，不是为了照顾非母语者，母语同事也是这样说。

### 每天的流程
1. 选一个抽象化的问题（例：「上流の槽で液位が上がらない」）
2. 对着手机按模板说 1–2 分钟，录音
3. 把录音的文字发给 AI，提示词：

```
以下は私が日本語で説明した内容です。
1) 不自然な表現を直して、自然な言い方を示してください
2) 現場のエンジニアが実際に使う言い方に寄せてください
3) 直した版を、私が音読しやすいように短い文に分けてください
（中国語で簡単に理由も添えてください）
```

4. 照着改好的版本**再说一遍**。这一步不能省，只看不说进步很慢。

## 4. 现场固定说法（打印出来带着）

| 场景 | 说法 |
|---|---|
| 没听清 | すみません、もう一度ゆっくりお願いします |
| 词不懂 | 今の「〇〇」は、どの部分のことですか？ |
| 请对方指图 | この図で、どこのことか指していただけますか？ |
| 请对方写下 | 念のため、Teams に書いていただけますか？記録にも残したいので |
| 确认理解 | 確認させてください。つまり、〇〇ということですね？ |
| 要时间想 | 少し整理してから、後でまとめて送ります |

重点：**"記録にも残したいので"**。同样是请人写下来，加上这句理由，意思就从"我听不懂"变成了"为了留记录"。

## 5. 四周安排

| 周 | 重点 | 完成标准 |
|---|---|---|
| 第 1 周 | 用 Copilot 建词汇库（至少 100 个词）；背熟固定说法 | 词汇卡建好，固定说法能脱稿说 |
| 第 2 周 | 每天词汇 + 口语；第一次现场回收 | 收集到第一批"真实没听懂的词" |
| 第 3 周 | 口语不看模板说；词汇卡加入现场回收的词 | 能不看稿讲完一个故障 |
| 第 4 周 | 在真实会议上用一次模板做报告 | 会后记录：哪里卡了、对方反应如何 |

## 附：这个计划依据的原理（以及可靠程度）

| 原理 | 可靠程度 |
|---|---|
| 噪音环境下，母语者靠熟悉的词汇和语境"预测补全"，非母语者补不回来，所以先学词能直接改善现场听力 | 心理语言学中较公认 |
| 间隔重复比集中突击记得牢 | 公认 |
| "输出 → 得到纠正 → 再输出"比只输入进步快 | 较公认 |
| 用 AI 当陪练比传统方法快多少 | 研究仍在初步阶段，没有定量结论 |
| 一直看实时字幕会拖慢听力进步 | 有一定研究支撑，非定论；用法得当（先听后看）反而有帮助 |

**什么情况下这个计划会失效**：
- 只看 AI 改好的版本、自己不再说一遍 → 输出练习没发生
- 词汇库只来自文档、不补现场真实没听懂的词 → 练的和现场脱节
- 每天时间被压缩到几乎为零 → 间隔重复的节奏断掉，效果会大幅下降

## 2. `app/editor.py`（冻结）

所有操作**原地修改** `program`，操作完把被改的行的 `cond` 做 `normalize`。
出错抛 `EditError`（`ValueError` 的子类），**出错时 program 必须保持原样**。

```python
class EditError(ValueError): ...

# 触点用 (r, k) 定位：r = 行号，k = layout(rung.cond).cells 里的下标（和 app/draw.py 的 tag 一致）
def contact_at(program, r, k) -> Contact
def set_contact(program, r, k, addr=None, nc=None)        # 改地址 / 改 a/b；None = 不改
def insert_series(program, r, k, contact, after=True)    # 在触点 k 的右边(after)/左边紧挨着串联插入
def append_series(program, r, contact)                   # 串联加到整行条件的最右边（线圈前）
def add_parallel(program, r, k1, contact, k2=None)       # 给 k1..k2 这一段并联一条只有 contact 的支路
def delete_contact(program, r, k)                        # 删掉触点；一行只剩它时 → EditError
def add_rung(program, index=None, rung=None)             # 默认 Rung(NO("X0"), Out("Y0"))，默认加到最后
def delete_rung(program, r)
def move_rung(program, r, delta)                         # delta=-1 上移 / +1 下移；越界 → EditError
def set_output(program, r, out)                          # 换输出（Out/OutT/OutC/Rst）

class History:
    def __init__(self, program): ...
    program: Program
    def apply(self, op, *args, **kw): ...   # 先存快照再执行 op(self.program, ...)；op 出错则不记录、原样抛出
    def undo(self) -> bool: ...             # 没得撤销返回 False
    def redo(self) -> bool: ...             # apply 之后 redo 栈清空
```

规则细节：
- `insert_series`：插在触点 k 所在的**最内层串联**里、紧挨着 k。如果 k 的父节点不是串联（是并联支路或整行就它一个），就把 k 换成 `Series([k, 新])`（或 `[新, k]`），再 normalize。
- `add_parallel`：k1 == k2（单个触点）时父节点是什么都可以；k1 < k2 时这一段必须是**同一个串联里连续的兄弟**。这一段换成 `Parallel([Series(这一段), Contact])`，再 normalize。不满足 → `EditError`。k1 > k2 → `EditError`。
- 地址合法性：前缀 + 十进制数字（`Y-1`、`XX1`、`X` 都不合法）。触点 X/Y/M/T/C；`Out` 只能 Y/M；`OutT` 只能 T 且 k ≥ 1；`OutC` 只能 C 且 k ≥ 1；`Rst` 只能 T/C。不合法 → `EditError`。
- 行号、k 越界 → `EditError`。

## 3. 界面

- 点触点 → 选中（黄色框）；点线圈 → 选中线圈；点空白 → 取消。选中位置由 `layout` + `draw.py` 的坐标反算，不要另写一套布局。
- 工具栏（放在梯形图区下方一行，或关卡栏下面，不能挡梯形图）：
  `[右插触点] [左插触点] [加并联] [删除] [a/b切换] [地址: ____] [行+] [行−] [上移] [下移] [撤销] [重做]`
  - 新插入的触点默认 `NO("X0")`，插完自动选中它，方便马上改地址。
  - 地址框是 `DirectEntry`，回车生效；不合法时框变红，并在状态栏显示 EditError 的消息。
  - "加并联"：选中一个触点时并联一条；**按住 Shift 再点第二个触点**选中一段，再按"加并联"就并联这一段。
  - 选中线圈时，工具栏换成：`[OUT] [OUT T] [OUT C] [RST]  地址: ____  K: ____`。
- 快捷键：`Delete` 删除、`Ctrl+Z` 撤销、`Ctrl+Y` 重做。
- 每次编辑成功后 `ctrl.load(新程序)`（PLC 重新开始、水槽归零是可以接受的）。
- 关卡模式：编辑 `session.program`；"恢复示例"/"参考答案"也要进 History（能撤销）。
- 关卡选择里加 `[空白沙盒]`：一行 `LD X0 / OUT Y0` 起步，不判定。
- 编辑时键盘 `0`/`1` 不能误触发 X0/X1（地址框有焦点时不响应）。

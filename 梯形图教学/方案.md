# PLC 梯形图教学演示程序 — 方案

> 目标：用一个能点、能动、能单步的小程序，学会看懂三菱风格梯形图的**基本功能**。
> 不追求做成真 PLC 编程软件，够学会就行。

| # | 问题 | 结论 |
|---|------|------|
| 1 | PLC 写法 | 三菱（X / Y / M / T / C，GX Works 风格） |

## 1. 为什么梯形图难懂 → 程序要解决什么

| 难点 | 程序里的对策 |
|------|-------------|
| 图是静态的，看不出"电"怎么流 | 通电的线和触点实时变绿（导通）/ 灰（断开） |
| 不知道 PLC 是**一轮一轮扫描**的 | 扫描指针从上往下逐行走，可单步、可慢放 |
| 输入、程序、输出三者关系混乱 | 画出 X 输入映像区 → 程序 → Y 输出映像区三块，扫描时分阶段高亮 |
| 不知道 X0 对应现实中什么东西 | 右边水槽场景：按钮、阀门、液位开关都标地址 |
| 工作中看到的是指令表/日文术语 | 梯形图旁同步显示指令表，术语带日文 |

## 3. 水槽场景的 I/O 分配（固定，全关卡通用）

| 地址 | 名称 | 日文 | 说明 |
|------|------|------|------|
| X0 | 启动按钮 | 起動ボタン | 点击按下，松开弹回（瞬时） |
| X1 | 停止按钮 | 停止ボタン | 同上 |
| X2 | 下限液位开关 | 下限レベルスイッチ | 水位 ≥ 下限时 ON |
| X3 | 上限液位开关 | 上限レベルスイッチ | 水位 ≥ 上限时 ON |
| Y0 | 给水阀 | 給水バルブ | ON 时水位上升 |
| Y1 | 排水阀 | 排水バルブ | ON 时水位下降 |
| Y2 | 完成指示灯 | 完了ランプ | 灯亮 |
| M0~M7 | 辅助继电器 | 内部リレー | 中间变量 |
| T0~T3 | 定时器（100ms） | タイマ | K50 = 5.0 秒 |
| C0~C3 | 计数器 | カウンタ | 上升沿计数 |

水位物理：每帧 `水位 += (Y0 ? 进水速度 : 0) − (Y1 ? 排水速度 : 0)`，限制在 0~100%。
两阀都不开时水位不动。水满溢出时水面闪红做提示（不会坏，只是提示"上限没写好"）。

## 4. 支持的指令（三菱 FX 风格的最小集合）

| 梯形图符号 | 指令 | 日文 | 含义 |
|-----------|------|------|------|
| ─┤├─ | LD / AND / OR | a接点 | 常开触点：元件 ON 时导通 |
| ─┤/├─ | LDI / ANI / ORI | b接点 | 常闭触点：元件 OFF 时导通 |
| 并联块串联 | ANB | — | 两段并联电路再串起来 |
| 串联块并联 | ORB | — | 两段串联电路再并起来 |
| ─( Y0 )─ | OUT Y0 | コイル | 线圈：本行导通 → 元件 ON |
| ─( T0 K50 )─ | OUT T0 K50 | タイマ | 导通持续 5 秒后 T0 触点 ON；断开立即复位 |
| ─( C0 K3 )─ | OUT C0 K3 | カウンタ | 每次由 OFF→ON 计 1，到 3 后 C0 触点 ON |
| ─[ RST C0 ]─ | RST C0 | リセット | 计数器清零 |
| ─[ END ]─ | END | — | 程序结束，回到开头 |

**不做**：SET/RST 普通位、上升沿 PLS/PLF、MOV/CMP 数据指令、积算定时器。（以后想学再加关卡。）

## 5. 关卡设计（8 关 + 沙盒）

每关结构：**① 说明（1 屏）→ ② 看示例运行 → ③ 小任务（改一处让它达成目标，自动判定）**

| 关 | 知识点 | 示例程序 | 小任务 |
|----|--------|----------|--------|
| 1 | a接点 + 线圈 | `LD X0 / OUT Y0`：按住启动才进水 | 改成按住停止按钮时排水（用 Y1） |
| 2 | b接点 | `LDI X3 / OUT Y0`：没到上限就一直进水 | 改成"水没低于下限时排水" |
| 3 | 串联 AND / 并联 OR | 按住 X0 **且** 未到上限才进水 | 让 X0 **或** X1 都能排水 |
| 4 | **自保持**（自己保持回路） | `LD X0 / OR Y0 / ANI X1 / OUT Y0`：按一下启动持续进水，按停止才停 | 把停止条件加上"到达上限 X3 自动停" |
| 5 | **扫描周期** + 双线圈陷阱 | 同一个 Y0 写两行，看只有最后一行生效 | 单步执行，回答"这一轮结束时 Y0 是什么" |
| 6 | 定时器 T | 到达上限后 T0 K50 计时，5 秒后排水 | 改成满 3 秒就排水 |
| 7 | 计数器 C + RST | 每次到达上限 C0 计 1，第 3 次亮完成灯 | 加一行：按停止按钮时清零计数器 |
| 8 | 综合 | 自动循环：给水→满了等 5 秒→排水→空了再给水，3 次后停，亮灯 | 无示例，自己补全空出来的两行 |
| — | **沙盒** | 空白程序，所有指令可用 | 自由搭建 |

第 5 关是关键关卡：单步时把 X 映像 / Y 映像的更新时机画出来，讲清楚
"输入在扫描开头一次性读入、输出在扫描结尾一次性写出"。

判定方式：每关定义一个检查函数（例：按下 X0 后 10 秒内水位达到上限且没溢出 → 通过）。

### 关键设计决定：梯形图内部用"串并联树"存储

每一行（ラング）存成一棵树：

```
Series[ Parallel[ NO(X0), NO(Y0) ], NC(X1) ]  →  OUT Y0
```

好处：
- **执行**简单：串联 = 全部导通，并联 = 任一导通，递归算一遍。
- **转指令表**简单：树一遍历就能生成 LD / OR / ANI / ANB / ORB。
- **画图**简单：串联横着排，并联竖着叠，自动算网格坐标。
- **编辑**不会画出非法电路（比如悬空的竖线），对初学者友好。

代价：画不出"桥式电路"这种奇怪接法——基本功能用不到，正好避开。

### 扫描执行的三个阶段（引擎核心）

```
每轮扫描:
  1. 输入采样   X映像 ← 读取水槽的按钮/液位开关
  2. 程序执行   第1行 → 第2行 → … → END
                 每行: 算树是否导通 → 写线圈到 Y/M 映像（Y 此时还没真的输出）
                 定时器按扫描时间累加；计数器检测上升沿
  3. 输出刷新   水槽阀门/灯 ← Y映像
```

单步模式下引擎是一个生成器（`yield` 每一行），UI 每次取下一步，就能"一行一行走"。

## 7. 分阶段实现

| 阶段 | 内容 | 完成标准 |
|------|------|----------|
| **P1 引擎** | `plc/` 全部 + 单元测试 | 命令行跑测试：自保持、T0 K50、C0 K3、双线圈 结果都对 |
| **P2 梯形图显示** | 画梯形图、通电变色、指令表、监视表、运行/单步按钮 | 关卡 4 的程序能看着它跑，用键盘模拟 X0/X1 |
| **P3 水槽场景** | 3D 水槽、按钮可点、水位物理、液位开关 | 关卡 4 完整可玩：按启动进水，按停止停 |
| **P4 关卡系统** | 8 关的说明、示例、判定；关卡选择画面 | 能从第 1 关打到第 8 关 |
| **P5 沙盒编辑** | 点选位置插入触点/并联分支/线圈，改地址，删除 | 能自己从零搭出关卡 4 的自保持 |
| **P6 打磨** | 中日术语提示、速度调节、示例程序存取 | 自己用一遍没卡壳 |

P1~P3 做完就已经能学到大部分东西；P5 编辑器最费工夫，放后面。

# PLC IO ↔ RS-485 联动模拟器（KELK 温水器 / 虚构协议）

三菱 PLC 的 IO（远程、在线、通水、加热、停止、确认、急停）怎样和温水器自有的 RS-485 协议联动的演示程序。

## 运行
Windows 双击 `run_v2.bat`（v2 双向通信）或 `run_v1.bat`（v1）。
第一次会自动 `pip install panda3d`；公司网络装不上的话，手动装一次即可。

手动运行：
```
pip install panda3d
python plc485_sim.py      # v1
cd v2 && python app.py    # v2
```

## 画面
- 左：X0～X6 输入按钮（X5/X6 按一下就弹起，X4 急停按下锁定）、SV 设定、Y10～Y13 输出灯、暂停/速度/重置
- 中：时序图（蓝色竖线扫描）、485 TX/RX、PV 曲线；紫色虚线 = 哪个 IO 引起的命令
- 右上：3D（灯管、水流、485 报文、硬线）
- 右下：16 个用例 + 故障注入

## 操作
- 空格：暂停/继续　R：重置
- 暂停后点时序图：查看该时刻的 IO 和最近报文的逐字段解码
- ← →：移动查看光标（Shift 加大步长）　[ ]：跳到上/下一条命令帧
- 窗口 1s + 速度 0.1x：可以看清单帧约 10ms 的报文

## 要点
- 急停走硬线，不经过 485；485 只是事后补发停止并确认
- Y12「加热许可」也是硬线：通信异常时 PLC 断开它，温水器靠硬线停下
- 报警复位后 X3 要重新给上升沿才会再启动（不会自动重启）

## 换成真协议
协议是虚构的，全部在 `FakeProtocol` 类；命令处理在 `Heater.receive`。拿到规格书后只改这两处。

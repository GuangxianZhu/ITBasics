## 3. 接口规格（冻结）

### 3.1 `plc/model.py` —— 数据结构

```python
from dataclasses import dataclass, field

@dataclass(frozen=True)
class Contact:              # 触点
    addr: str               # "X0" "Y1" "M3" "T0" "C2"
    nc: bool = False        # False=a接点(常开)  True=b接点(常闭)

def NO(addr) -> Contact     # 常开触点的简写
def NC(addr) -> Contact     # 常闭触点的简写

@dataclass
class Series:               # 串联
    items: list             # 元素是 Contact / Series / Parallel

@dataclass
class Parallel:             # 并联
    items: list

def normalize(node):
    """返回规范化后的新树（不修改原树）：
       - Series 里套 Series、Parallel 里套 Parallel → 拍平
       - 只有 1 个元素的 Series/Parallel → 换成那个元素本身
       - 空的 Series/Parallel → ValueError
    """

@dataclass(frozen=True)
class Out:   addr: str          # OUT Y0 / OUT M0
@dataclass(frozen=True)
class OutT:  addr: str; k: int  # OUT T0 K50   （单位 100ms，K50 = 5 秒）
@dataclass(frozen=True)
class OutC:  addr: str; k: int  # OUT C0 K3
@dataclass(frozen=True)
class Rst:   addr: str          # RST C0 / RST T0

@dataclass
class Rung:                 # 一行（ラング）
    cond: object            # Contact / Series / Parallel（不允许为空）
    out: object             # Out / OutT / OutC / Rst

@dataclass
class Program:
    rungs: list = field(default_factory=list)   # END 是隐含的，不存
```

地址规则：前缀 X/Y/M/T/C + 十进制数字。只支持这 5 种。非法地址 → `ValueError`（在 `PLC.__init__` 时检查即可）。

### 3.2 `plc/engine.py` —— 扫描执行

```python
@dataclass
class Step:
    phase: str          # "input" | "rung" | "output"
    rung: int | None    # phase=="rung" 时为行号（0 起），否则 None
    powered: bool | None  # phase=="rung" 时为该行条件是否导通，否则 None

def evaluate(cond, read, trace=None) -> bool:
    """read(addr)->bool 读元件状态。
       触点导通: 常开 = read(addr)；常闭 = not read(addr)
       Series = 全部导通；Parallel = 任一导通。
       trace 是 dict 时：对树里每个节点 n，写 trace[id(n)] = 该节点右端是否有电。
         触点右端 = 左端有电 and 触点导通
         Series：依次传递，节点右端 = 最后一个子节点右端
         Parallel：每个分支左端 = Parallel 左端；Parallel 右端 = 任一分支右端
         整棵树左端 = True（左母线）
       注意：evaluate 不做 normalize，trace 的 key 是传入那棵树里节点的 id。
    """

class PLC:
    def __init__(self, program, scan_ms=10): ...
    scan_count: int          # 已完成的扫描轮数
    last_power: list[bool]   # 每行最近一次执行时是否导通（初始全 False）

    def set_input(self, addr, value): ...   # 设置 X 的"外部端子"，下一次输入采样时才进 X 映像
    def get(self, addr) -> bool: ...        # 读映像：X/Y/M 的映像值；T/C 为"到达"触点状态
    def output(self, addr) -> bool: ...     # 读 Y 的"外部端子"（只在输出刷新时更新）
    def timer_ms(self, addr) -> int: ...    # 定时器当前累计毫秒
    def counter_value(self, addr) -> int: ...
    def steps(self):                        # 生成器：执行一整轮扫描，每完成一个阶段 yield Step
    def scan(self): ...                     # 执行一整轮 = 把 steps() 跑完
```

**一轮扫描的语义（必须严格照做）**

1. `input`：所有 X 映像 ← X 外部端子。yield `Step("input", None, None)`。
2. 对每一行 i 按顺序：
   - `p = evaluate(rung.cond, self.get)`，`last_power[i] = p`
   - 执行输出：
     - `Out(a)`：a 的映像 = p（Y 和 M 都是写映像；同一地址多行写 → 最后一行说了算 = 双线圈）
     - `OutT(a,k)`：p 为真 → 累计 += scan_ms，上限 k*100；到达 = 累计 >= k*100。p 为假 → 累计=0，到达=False
     - `OutC(a,k)`：p 由假变真（与**这条指令上一次执行时**的 p 比）且 当前值 < k → 当前值 += 1；到达 = 当前值 >= k。保持到 RST。
     - `Rst(a)`：p 为真 → a 的当前值/累计清 0，到达=False
   - yield `Step("rung", i, p)`
   - 后面的行读到的是**已经被前面行改过的**映像（同一轮内就生效）
3. `output`：所有 Y 外部端子 ← Y 映像。`scan_count += 1`。yield `Step("output", None, None)`。

所有元件初始为 False / 0。从没写过的元件读出 False。

### 3.3 `plc/to_il.py` —— 指令表

```python
def to_il(program) -> list[str]
def to_il_rungs(program) -> list[list[str]]   # 按行分组、不含 END（UI 高亮当前行对应的指令用）
```
每条一个字符串，格式 `"助记符 操作数"`，单空格分隔：`"LD X0"` `"ANI X1"` `"OUT T0 K50"` `"OUT C0 K3"` `"RST C0"`，最后一条固定是 `"END"`。先对每行 `normalize`。

生成规则（三菱标准）：
- 触点作为**块的开头**：`LD` / `LDI`
- Series 的后续元素：触点 → `AND` / `ANI`；Parallel → 以 LD 开头生成该块，然后 `ANB`
- Parallel 的后续分支：触点 → `OR` / `ORI`；Series → 以 LD 开头生成该块，然后 `ORB`
- Series 的第一个元素若是 Parallel：直接展开（它本身以 LD 开头），不加 ANB
- Parallel 的第一个分支若是 Series：直接展开，不加 ORB

例子见 `tests/acceptance/test_p1_il.py`。

### 3.4 `plc/layout.py` —— 网格坐标（给画图用）

```python
@dataclass
class Layout:
    width: int                       # 列数
    height: int                      # 行数（这一个 ラング 占几行）
    cells: list                      # [(Contact, col, row), ...] 按从左到右、从上到下深度优先顺序

def layout(cond) -> Layout          # 先 normalize
```
- 触点：1×1
- Series：子块横着排，宽 = 各宽之和，高 = 最大高，子块上对齐（row 偏移 0）
- Parallel：子块竖着叠，宽 = 最大宽，高 = 各高之和，左对齐；较窄的分支右边用横线补齐到最右（画图时处理，不占 cells）

线圈不在 `layout` 里，画在整行最右端。

### 3.5 `sim/tank.py` —— 水槽（P3）

```python
class Tank:
    def __init__(self, level=0.0, fill_rate=10.0, drain_rate=10.0, low=20.0, high=80.0): ...
    level: float        # 0~100（%）
    overflow: bool      # 水位到 100 且进水阀开 → True；之后水位降到 100 以下 → False
    def step(self, dt, inlet: bool, drain: bool): ...
        # level += (fill_rate if inlet else 0)*dt - (drain_rate if drain else 0)*dt，夹在 [0,100]
    def sensors(self) -> dict:
        # {"X2": level >= low, "X3": level >= high}
```

### 3.6 `sim/runner.py` —— 无界面联动（P3），关卡判定和测试都用它

```python
class Runner:
    def __init__(self, program, tank=None, scan_ms=10): ...   # tank 为 None 时新建 Tank()
    plc: PLC
    tank: Tank
    time: float                       # 已经过的秒数
    def press(self, addr): ...        # 按住按钮（X0 / X1）
    def release(self, addr): ...
    def tick(self): ...               # 一次：把按钮+tank.sensors() 写进 set_input → plc.scan()
                                      #       → tank.step(scan_ms/1000, plc.output("Y0"), plc.output("Y1"))
                                      #       → time += scan_ms/1000
    def run(self, seconds): ...       # 反复 tick，直到多跑了 seconds 秒（四舍五入到整数次 tick）
```
图形界面也必须通过 `Runner`（或同样顺序的逻辑）驱动，保证界面和判定行为一致。

### 3.7 `levels/` —— 关卡（P4）

`levels/__init__.py` 提供 `ALL_LEVELS`：8 个关卡模块的列表，按 1~8 排序。每个模块有：

| 名称 | 类型 | 说明 |
|------|------|------|
| `ID` | int | 1~8 |
| `TITLE` | str | 例："第4关 自保持（自己保持回路）" |
| `INTRO` | str | 说明，一屏以内，中文为主、术语带日文 |
| `KIND` | str | `"task"` 或 `"quiz"`（只有第 5 关是 quiz） |
| `EXAMPLE` | Program | 示例程序（第 8 关：故意缺两行的不完整程序） |
| `TASK` | str | （task）任务说明 |
| `check(program)` | 函数 → `(bool, str)` | （task）用 Runner 跑脚本化的按钮操作，判断是否达成；str 是给用户看的提示 |
| `SOLUTION` | Program | （task）参考答案，`check(SOLUTION)` 必须通过 |
| `QUESTION` / `CHOICES` / `ANSWER` | str / list[str] / int | （quiz）问题、选项、正确选项下标 |

要求：`check(EXAMPLE)` 必须**不**通过（否则任务没意义）。关卡内容按 `方案.md` 第 5 节。

## 6. 常见坑提示

- 自保持：`LD X0 / OR Y0 / ANI X1 / OUT Y0` —— 读 Y0 的是**映像**，不是外部端子。
- 定时器的到达触点在执行 `OUT T` 的那一刻更新；排在它后面的行同一轮就能看到。
- 计数器按住按钮不放只算 1 次（看上升沿）。
- 双线圈不是错误，要能正常运行（关卡 5 就是教这个）。
- 水槽 `X2`/`X3` 是液位开关，`X0`/`X1` 是按钮，按钮是瞬时的（松开就 OFF）。

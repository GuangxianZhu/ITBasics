# 涵道无人机（Blender 脚本建模 + 飞行演示 + 爆炸图）

一架**原创**的 3 寸涵道穿越机（cinewhoop），全部零件由 `build_drone.py` 在 Blender 里用代码生成，不对应任何厂家的产品。
同一个 `.blend` 里有两段动画：飞行演示 和 爆炸图。

## 用法

双击 `启动.bat`，它会依次：

1. `git pull --ff-only origin main` 检查更新（没网或没装 git 就跳过）
2. 找 Blender（`blender_path.txt` → PATH → `Program Files\Blender Foundation\Blender*` → Steam）
3. 后台运行 `build_drone.py`，几秒钟生成 `output\drone.blend`
4. 让你选：
   - **[1] 用 Blender 打开**：按空格播放。时间线上有标记，会自动切相机
   - **[2] 渲染 MP4 视频**：EEVEE，1280×720，750 帧，用显卡，几分钟 → `output\drone_demo.mp4`
   - **[3] 渲染 4 张预览图**：Cycles → `output\render_*.png`

找不到 Blender 时，把 `blender.exe` 的完整路径写进同目录的 `blender_path.txt`（这个文件不会提交到 git）。
支持 Blender 4.2 ~ 5.x。

## 动画背后的原理

**为什么前飞、转弯要歪着飞**（公认结论）
四旋翼的四个桨都朝机身 +Z 方向推，推力方向改不了，只能把整个机身歪过去。
要让飞机获得加速度 **a**，推力必须等于 m(**a** + **g**)，所以机身 +Z 轴要对准 **a** + **g**。
脚本就是这么算姿态的：先算航线每一帧的加速度，再让机身轴对准 **a** + **g**，机头转向速度方向。
所以姿态不是手 K 的，是从航线推出来的。这条航线最大倾角约 37°，出现在两头的弯道（向心加速度最大）。

**桨转速 ∝ √推力**（公认结论，螺旋桨的静推力 ∝ 转速²）
脚本按每帧需要的推力 |**a** + **g**| 算桨速：起飞瞬间和过弯时转得快，下降开始时转得慢。
注意：真实 3 寸桨悬停约每分钟两三万转，30 fps 下每帧要转好几千度，看起来反而像不动或倒转（车轮效应）。
所以动画里的转速是故意放慢的“示意转速”，高速时再叠一层半透明的桨盘虚影。

**对角两只桨同向、相邻两只反向**（公认结论）
每个桨转的时候都会给机身一个反扭矩。两对反向的桨扭矩互相抵消，机身才不会原地打转。
要转机头时，就让一对桨加速、另一对减速。动画里没有做这个差速，只做了统一的油门。
同样的原因，正桨和反桨的叶片是镜像的（`spin` 属性 = +1 俯视逆时针，−1 顺时针），不能装错位置。

**桨叶为什么是扭的**（公认结论）
桨叶每个截面的安装角 β = atan(螺距 / 2πr)：越靠根部 r 越小，角度越大；越靠桨尖角度越小。
这样桨转一圈，每个截面“前进”的距离都差不多等于螺距。脚本里取螺距 50 mm，根部把角度限制在 40° 以内。

**涵道的作用**（有研究支持，但效果取决于设计）
涵道最直接的作用是保护桨，室内或贴近人群飞时撞墙不打断桨。
另外，桨尖和涵道内壁的间隙很小时（这里单边 1 mm），能减少桨尖涡流，低速时推力效率会好一点。
代价是重量和前飞阻力都增加，所以涵道机通常飞得慢、续航短。
效率能提升多少，对间隙、入口圆角这些细节很敏感。这个模型的入口圆角是凭经验画的，没有做过气动验证。

## 改参数

尺寸都在 `build_drone.py` 开头（单位 mm）：

- `MOTOR_XY` 电机位置（决定轴距）
- `DUCT_R_IN` / `DUCT_R_OUT` 涵道内外径
- `PROP_PITCH` 桨的螺距
- `CAM_TILT` 相机上仰角

飞行参数：`H` 巡航高度、`LOOP_A` / `LOOP_B` 8 字大小、`F_LOOP` 飞 8 字用的帧数（帧数越少越快，倾角越大）。
爆炸方向和顺序在 `EX` 字典里，每条是 `(x, y, z, 出场时刻 0~1)`。

## 和三视图草稿的差别

- **电池往前挪了**：草稿里电池伸出机身后方 20 mm，建模时发现会和后面伸出的两根天线撞上。现在电池和机身罩前后对齐（长 56 mm），天线从机身罩后壁的两个孔伸出。
- **高了一点**：电池厚 20 mm，电池顶到脚垫底约 55 mm（草稿写的是 53 mm）；算上绑带搭扣约 57 mm。

## 有意简化

- 飞控、电调、图传上的元件都是示意方块，板子之间的排线没有画
- 电机内部（定子、绕组、磁钢）没有建，只有外壳
- 螺丝只画了涵道法兰和相机转轴上的几颗
- 没有做四个电机之间的差速，所以动画里的转向（偏航）是“直接转过去”的，不是靠桨速差转过去的

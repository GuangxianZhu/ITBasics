# PLC 网关模拟器（网页版）

清洗机（槽式，软件不改）↔ PLC 网关 ↔ 温水器（只用串口）的完整模拟器。
离线网页，不用装任何东西：双击上一层的 `run_web.bat`（先 `git pull` 再用默认浏览器打开 `index.html`）。界面可切 **中文 / English / 日本語**。

做法按 [`../时序图/README.md`](../时序图/README.md) 第 3～5 节。
时序图不再是手画的：模拟器按参数实际跑一遍，图是跑出来的结果。

## 时序图怎么读

- **分块**：和原来的图同一套分区和顺序（清洗机内部 → 清洗机→PLC → PLC→清洗机 → PLC→温水器 → 温水器→PLC → 温水器状态 → PLC 内部 → 线路）。点分区标题收起 / 展开
- **视图**：全部 / 启动·结束 / 供水 / 轮询 / 报警，就是原来 4 块图各自用到的信号；「信号…」里逐个勾
- **筛选**：隐藏周期轮询帧（报警图不画每一次轮询）、只看有变化的信号、串口按命令分行（通水 / 温度 / 运转 / 状态读出 / 读回 / 复位 / 报警详细 各一行）
- **压缩空闲时间**：30 s 等待这种没事发生的段压成一条斜线带，标「省略 xx s」；刻度仍是真实时间
- **阶段线**：脚本动作和关键事件（满 30 s、安定 DO、通信异常…）自动编号 ①②③
- **因果箭头**：运转 IO → 启动 3 帧，状态应答 → DO 变化，第 3 次超时 → 重故障，复位 → 复位帧
- **光标**：点击放 A，Shift + 点击放 B，显示 Δ；左边「光标处」一列是 A 时刻每个信号的值
- **操作**：拖动平移，Ctrl + 滚轮 / 双指缩放，双击放大，← → 移光标，[ ] 上 / 下一帧，空格播放
- **导出**：当前视图的 SVG / PNG（固定浅色，图下面自动写上改过的参数）、事件日志 CSV、帧列表 CSV

## 换协议

帧格式、命令码、寄存器地址、状态位顺序、报警编号集中在 `core.js` 开头，换协议只改这里
（帧长度量级：写命令十来个字节、ACK 3 字节、报警详细应答 130 多字节）：

- 温水器串口帧：`SU_CMD`、`suReq` / `suRsp` / `suAck` / `suNak`
- 清洗机侧 Modbus：`MB_ADDR`（帧结构和 CRC16 是标准 Modbus RTU）
- 状态位 / 报警编号：`ST`、`ALM`

参数表里的标记：「前提」是清洗机 / 温水器侧的值，「P」是 PLC 本方案，「演示」是为了演示调过的值（升温速度、安定判定、PLC 扫描周期、清洗机反应时间…），
「未定」对应时序图 README 第 5 节还没定的两条（清洗机断线判定 5 s、重故障时清洗机关运转 / 通水）。

## 模拟器里补定的做法

时序图 README 没写到、模拟器里定了的地方：

- PLC 等 IO 和写温度都到齐再转发（「转发前等待」默认 100 ms）。设成 0 可以看到先按旧温度发一遍再补发
- 温水器状态机：停止中 →（通水 ON）→ 通水中 →（运转 ON）→ 运转中。无效的命令回「现在不能执行」的 NAK
- 停止类 / 漏液报警时温水器自己回到停止中（入口阀关）
- 装置结束后清洗机停 Modbus；PLC 在装置结束期间不判清洗机断线
- PLC 重启后直接读温水器（不等 30 s）；读不到 3 次就按通信异常处理

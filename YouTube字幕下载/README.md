# YouTube 下载器（视频 / 音频 / 字幕）

粘贴链接，选「视频 / 音频 / 字幕」，加入队列下载。基于 yt-dlp，PySide6 界面。

## 使用
1. 双击 `启动.bat`（需要已安装 Python）
   - 第一次会安装 PySide6、ffmpeg、deno、yt-dlp，要几分钟
   - 之后每次启动只顺便更新 yt-dlp
2. 粘贴链接（可多个，一行一个）→ 可先点「🔍 解析」看标题、可用画质、字幕
3. 选上方标签页：🎬 视频 / 🎵 音频 / 💬 字幕，设好选项
4. 点「⬇ 加入队列并开始」，右侧队列显示进度、速度、剩余时间
5. 选中任务可「取消」「重试」（断点续传）「打开文件夹」；双击任务也能打开文件夹

默认保存到 `下载\YouTube下载`，所有设置关闭时自动保存。

## 选项
| 模式 | 选项 | 说明 |
|---|---|---|
| 视频 | 画质 | 选的是“最高不超过”，没有 1080p 就自动取最接近的 |
| | 格式 | MP4 优先 H.264+AAC，Windows 播放器、PPT、手机都能放；MKV 画质优先（可能是 VP9/AV1） |
| | 嵌入字幕 | 字幕封进视频文件，播放器里可开关 |
| 音频 | 格式 | MP3 通用；M4A 基本不损失；Opus 体积小；原始=不转码 |
| | 码率 | 只对 MP3 有效。YouTube 原始约 128~160 kbps，选更高不会更清楚 |
| 字幕 | 语言 / 格式 | 同原来的字幕工具：SRT、TXT（去重复行）、TXT 带时间、VTT |
| | 限流时改下原文 | 自动翻译字幕（英文视频要中文）常被 429，失败时改下原文字幕 |
| 通用 | 播放列表 | 勾选后整个列表下到「列表名」子文件夹，文件名带序号 |
| | 浏览器登录状态 | 只在“请登录确认不是机器人”或频繁 429 时用；Firefox 最稳 |

## 常见问题
- **403 / Unable to extract**：YouTube 改版了，点右下角「更新组件」后重开
- **429 / 请求太频繁**：等一会儿，或借用浏览器登录状态；字幕模式会自动等待重试
- **状态栏 ffmpeg ✗ 或 deno ✗**：重新双击 `启动.bat`
- **取消后的文件**：放在保存位置下的 `.下载中` 文件夹里，重试会从断点继续；下载完成后自动清理
- 有 DRM 的内容（付费影片等）yt-dlp 不支持，下载不了

## 结构
```
app.py              入口（检查组件，启动界面）
ui/main_window.py   界面：只读写任务字段，不直接碰 yt-dlp
core/
  task.py           任务 = 链接 + 选项 + 状态 + 进度
  manager.py        队列 + 2 个工作线程，取消/重试
  options.py        界面选项 → yt-dlp 参数（加功能主要改这里）
  runner.py         执行任务：进度回调、错误提示、字幕逐个下载+重试
  probe.py          解析链接（不下载）
  env.py            ffmpeg/deno 路径、配置文件（%APPDATA%\YouTubeDownloader）
post/subtitles.py   VTT → SRT/TXT（合并自动字幕的滚动重复行）
```

### 数据流
```
界面 → Task(链接+选项) → Manager 队列 → 工作线程 runner.run()
        ↑                                   │ yt-dlp 进度回调
        └──── 界面每 0.3 秒读 Task 字段 ←────┘ 写 percent/speed/eta/status
```
界面和下载线程之间只通过 Task 字段和日志队列交流，不跨线程操作界面，所以不会卡死。

### 为什么每个任务有自己的临时文件夹
同一个视频同时下“视频”和“音频”时，两个任务会写同名的中间文件互相覆盖；
另外保存位置已有同名视频时，音频任务会把它当源文件、转完后删掉。
所以下载中的文件放 `.下载中\<任务号>`，音频模式整个在里面完成后再移出来。

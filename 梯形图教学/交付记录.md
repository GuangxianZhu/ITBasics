## 验收方法（验收方用，实现方可忽略）

```bash
cd 梯形图教学
LAST=$(grep -oP '已验收基准: \K[0-9a-f]{7,40}' 交付记录.md | tail -1)  # 上次验收点
(cd tests/acceptance && sha256sum -c SHA256SUMS)                # ① 验收测试没被改
python -m pytest tests -q                                       # ② 测试
git diff --stat $LAST..HEAD -- .                                # ③ 改了哪些文件
git diff $LAST..HEAD -- . ':!docs/shots'                        # ④ 只看新增/改动的代码
# ⑤ 看本文件新增的节、看 docs/shots/P<n>_*.png
# 通过后: 在本文件末尾追加 "## P<n> 验收通过" 一节，写一行  已验收基准: <commit hash>
```

不通过时，验收方在本文件末尾追加"验收意见 P<n>"一节，实现方逐条处理后再追加交付节。

### 完成内容
- plc/model.py：数据模型（Contact、Series、Parallel、Out/OutT/OutC/Rst、Rung、Program），规范化函数
- plc/engine.py：PLC 扫描引擎，支持输入采样→行执行→输出刷新三阶段扫描
- plc/to_il.py：梯形图→指令表转换（支持 LD/LDI/AND/ANI/OR/ORI/ANB/ORB/OUT/RST/END）
- plc/layout.py：梯形图网格坐标计算（支持触点、串联、并联的布局）
- 核心功能：
  - 触点求导（常开/常闭 + 左端电压 = 右端是否有电）
  - 串联：从左到右传递电压
  - 并联：每个分支左端相同，右端求或
  - 定时器：累计时间驱动，单位 100ms（K值乘以100）
  - 计数器：上升沿计数，达到 K值后保持
  - RST 输出：重置定时器或计数器
  - 追踪求导：用 trace 字典记录每个节点右端电压

### 手动检查方法
```python
from plc.model import *
from plc.engine import PLC

# 简单例子：X0 按下时 Y0 输出
prog = Program(rungs=[
    Rung(NO("X0"), Out("Y0"))
])
plc = PLC(prog, scan_ms=10)
plc.set_input("X0", True)
plc.scan()
assert plc.output("Y0") == True  # Y0 输出为真
```

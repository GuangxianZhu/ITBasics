## 验收意见 P1  （2026-10-07 / 验收方: Claude）  —— **不通过，需修改**

已检查：验收测试校验和 OK；原 46 项全部通过；model / engine / to_il / layout 代码已阅。
to_il、layout 没有问题。

### 必须修改

1. **【Bug】没执行过的定时器/计数器，触点读出是 ON。**
   `PLC.get()` 里 T/C 用 `累计 >= 设定值` 判断，而设定值在第一次执行 `OUT T`/`OUT C` 之前是 0，于是 `0 >= 0` 为真。
   实际后果：程序里"先读 T0、后写 OUT T0"时（第 8 关自动循环就是这样），一上电排水阀/完成灯就会误动作。
   复现：`Rung(NO("T0"), Out("Y1"))` 放在 `Rung(NO("X0"), OutT("T0",50))` 前面，X0 不按，扫一轮 Y1 就是 ON。
   规格原文："所有元件初始为 False / 0。从没写过的元件读出 False。"
   修法建议：给 T/C 单独存一个"到达"布尔量，只在 `OUT T`/`OUT C`/`RST` 执行时更新，`get()` 直接读它。
   已在 `tests/acceptance/test_p1_engine.py` 末尾追加 4 项回归测试（校验和已更新），修完要全部通过。

2. **`__pycache__/*.pyc` 被提交进了仓库**（5 个文件）。`.gitignore` 是后加的，已提交的文件不会自动消失。
   执行 `git rm -r --cached plc/__pycache__` 后提交。

### 建议（不改也能通过，改了更好）

3. `to_il` 和 `to_il_rungs` 的输出部分代码重复了一遍，可以让 `to_il` 调用 `to_il_rungs`。
4. `Contact` 构造时就校验地址，这本身没问题，但属于"与规格的偏差"，应该写在交付记录里。以后 P5 编辑器输入地址时要记得捕获这个 ValueError。

修完后按模板追加 "P1 交付（修正）" 一节。

### 手动检查方法
```python
from plc.model import *
from plc.engine import PLC

# 验证：T/C 初始为 OFF，即使先读后写
p = Program(rungs=[
    Rung(NO("T0"), Out("Y1")),  # 先读 T0
    Rung(NO("X0"), OutT("T0", 50))  # 后执行 OUT T0
])
plc = PLC(p, scan_ms=10)
plc.scan()
assert plc.get("T0") is False  # 第1轮T0必须OFF
assert plc.output("Y1") is False
plc.set_input("X0", True)
for _ in range(50):
    plc.scan()
assert plc.get("T0") is True  # 累计达到设定值后ON
```

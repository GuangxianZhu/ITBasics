# 路由器定时重启（Buffalo WSR-5400XE6）

每天凌晨自动重启家里的 Buffalo 路由器，用来预防长时间运行后偶尔卡死、变慢。

## 用法

1. 双击 **`启动.bat`**。它会先 `git pull` 拉取 main 上的更新，然后装依赖（requests、cryptography），最后打开菜单。
2. 第一次运行时会让你输入路由器的密码。输入时屏幕上不显示，保存时会加密。
3. 菜单里先选 **1) 测试登录**。这一步只登录、不重启，看到 `OK` 再继续。
4. 选 **3) 设置每日自动重启**，输入时间（默认 `04:00`），完成后就会每天自动跑。
5. 想看结果就选 **5) 查看日志**，或直接打开 `logs\reboot.log`。

> **前提**：到了设定时间，这台电脑必须是开机状态，Windows 账号也要处于登录状态（锁屏可以，注销不行）。
> 电脑如果在睡眠，计划任务会尝试把它唤醒，但这取决于电源设置里有没有允许「唤醒定时器」。

## 原理

| 步骤 | 请求 | 说明 |
|---|---|---|
| 取公钥 | `GET /login.html` | 页面里内嵌了一把 RSA 公钥（`<textarea id="privkey">`） |
| 登录 | `POST /login.html` | 密码先用这把公钥做 RSA **PKCS#1 v1.5** 加密，再转成 Base64，放进 `nosave_encryptedPassword` 字段发送。浏览器里的 JSEncrypt 做的就是这件事。服务端登录成功后会下发 `SessionID` cookie |
| 上报电脑时间 | `GET /login_time.html` → `POST /redirect.html` | 登录后路由器会先把浏览器带到这个页面，页面里的 JS 自动把电脑时间（`nosave_PCTIME`）提交上去。**不做这一步，所有管理页面都会被弹回 login_time.html**。这一步是第一次实测时才发现的 |
| 防呆检查 | `GET /Ajax_get_value.html&action=GetMovingRestore` | 官方页面在「スマート引っ越し」恢复设置期间会拒绝重启，脚本照着做同样的检查 |
| 取令牌 | `GET /init.html` | `rebootForm` 里有一个一次性的 `nosave_session_num`，每次打开页面都会变，作用类似 CSRF 令牌 |
| 重启 | `POST /init.html` | 发送 `nosave_reboot=1` 和刚拿到的那个 `nosave_session_num` |
| 确认 | TCP 探测 :80，再探测外网 | 先确认路由器掉线，再等它重新上线，最后等外网恢复，结果都写进日志 |

**为什么 PKCS#1 v1.5 加密每次的结果都不一样？** 因为填充里带了随机字节。所以不能把浏览器里抓到的密文抄下来反复使用，必须每次重新加密。

## 安全设计

- **密码不是明文**：`config.ini` 里的密码用 Windows **DPAPI** 加密，密钥绑定你的 Windows 账号。同一个账号下跑的计划任务能解开；把文件拷到别的电脑、或换个账号，就解不开了。`config.ini`、`logs/`、`debug/` 都写进了 `.gitignore`，不会被推到 GitHub。
- **时间窗防呆**：计划任务只会在设定时间之后的 90 分钟内真正执行重启（可以在 `config.ini` 里改 `window_minutes`）。这样即使任务因为某种原因在白天被补跑，也不会大白天把全家的网断掉。
- **只尝试登录一次**：如果密码错了，脚本直接报错退出，不会反复重试，免得触发路由器的登录锁定。

## 什么情况下会失效

- **固件更新后，登录或重启的接口变了**。这时日志会提示失败，`debug/` 文件夹里保存了每一步路由器返回的页面（里面不含密码），拿来给 Claude 看就能重新适配。
- **到点时电脑没开，或者账号已注销**：任务不会运行，这一天就跳过。
- **路由器已经彻底卡死、管理页面也打不开**：脚本发不出重启请求。这个工具只能起「预防」作用，救不了已经死机的路由器。真要兜底，得用智能插座之类的方式直接断电。
- **只允许一个人登录**：脚本一登录，你在浏览器里打开的管理页面就会被踢回登录页（这是实测看到的）。
- **你正开着路由器管理页面时，脚本恰好到点运行**：Buffalo 的管理页面可能同时只允许一个会话登录，脚本可能把你挤下线，或者自己登录失败。凌晨基本碰不到这种情况。

## 命令行

```
python router_tool.py --check            只测试登录
python router_tool.py --reboot-now       立即重启（会再确认一次；加 --yes 跳过确认）
python router_tool.py --scheduled        计划任务模式（带时间窗防呆）
```

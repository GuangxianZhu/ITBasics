# 干法刻蚀机（ICP 刻蚀机教学：操作机台跑一片晶圆）

一台**原创**的 ICP 导体刻蚀机，在网页里一步一步操作：晶圆从晶圆盒出发，经过负载锁、真空传输腔，进工艺腔刻蚀，再放回晶圆盒。
不对应任何厂家的具体型号。完整的规划见 [搭建路线.md](搭建路线.md)；这一版是简化版，对应路线里阶段 1–4 的"能操作、能跑完一次工艺"部分。工艺腔和机械手已经换成 Blender 细模型。

## 用法

双击 `启动.bat`（会先 `git pull` 检查更新），或者直接双击 `output\干法刻蚀机_离线版.html`。不用联网，不用装任何东西。

- **运行**页：点"▶ 下一步"一步一步跑 15 步；勾"自动连续运行"就自己跑完。速度可选 1× ~ 10×。每一步都写了"现在在干什么"和"为什么"。
- **配方**页：改腔压、源功率、偏压、Cl₂ / HBr / O₂、卡盘温度、过刻。下面实时显示按这个配方预计的刻蚀速率、离子能量、选择比。
  预置了几个"错误配方"（不加偏压、偏压太高、只用 Cl₂、不过刻），跑一下就能看出各自出什么问题。
- **零件**页：点零件名或直接点 3D 模型里的零件，看它是干什么的。顶栏可以剖开工艺腔、拖"拆开"滑杆。
- 左下角：**剖面**（晶圆中心那根 60 nm 栅极线条，离子是蓝色短线，自由基是橙色点）和**趋势图**（负载锁压力、腔压、源功率、反射功率、偏压、光谱终点）。
- **反应腔粒子动画**（示意，数量和速度不是真实比例）：气体分子（灰白）从喷嘴进来；起辉后被打碎成电子（青）、离子（红）、自由基（黄绿）；自由基吸附在晶圆上，离子进鞘层被偏压加速、拖着尾迹垂直打下来，打到吸附了自由基的地方才生成产物 SiCl₄（橙），产物随气流穿过约束环被分子泵抽走。不加偏压、刻穿以后、没有自由基时，产物都会明显变少。
- 跑完弹出结果：刻干净没有、侧壁直不直、栅氧保住没有、光刻胶够不够、刻得快不快，不合格的会说原因。

## 工艺模型（简化，趋势对、数量级对，系数是估计值）

- 等离子体密度 ∝ 源功率；离子能量 ≈ 偏压功率 ÷ 离子电流（离子电流 ∝ 密度）
- 往下刻：离子和自由基"串联"，哪个少就被哪个卡住（离子—自由基协同）；离子的刻蚀产额 ∝ √E − √E阈值
- 往侧面刻：自由基自己的化学反应（随温度升高），被 HBr / O₂ 形成的侧壁钝化层挡掉一部分
- 栅氧、光刻胶的消耗都随离子能量上升，HBr / O₂ 提高对栅氧的选择比
- 刻蚀速率中心快、边缘慢（差几个百分点）；光谱信号 ∝ 还没刻穿的面积，掉到一半判为终点

代码在 `web/etch_core.js`（`model()`、`etchTick()`、`oesTick()`、`evaluate()`），网页和 VR 共用这一份，见下面「给 VR 用」。

## 模型

工艺腔 PM1（含 PM2 / PM3 的外观）和两个机械手是 `build_etcher.py` 在 Blender 里用代码建的，导出 `output/etcher_detail.glb`（约 3 MB、10 万三角面），打包时以 base64 嵌进离线 html。
晶圆盒、EFEM、负载锁、传输腔外壳还是网页里代码搭的简模，下一轮再细化。

- 剖开工艺腔能看到：腔壁和内壁涂层的厚度、内衬、约束环的槽、静电卡盘里的吸附电极 / 加热层 / 冷却水道 / 背氦沟槽、边缘环的台阶、摆阀阀板、分子泵转子。
- 会动的：闸阀门（`slit__door`）、升降针（`pins`）、摆阀阀板按开度摆动（`pendulum__plate`）、分子泵转子一直转（`turbo__rotor`）。
- 物体名就是网页里的零件 id；`id__子名` 是同一个零件里单独会动的部分。
- 金属度都压在 0.55 以下（MyVRToyBox 没有反射探针），以后可以直接导进 VR。
- 颜色按材料分（铝和不锈钢有拉丝纹，喷粉外壳有细颗粒，地面是带通风孔的架空地板），纹理都是网页里程序生成的，模型带盒式贴图坐标（1 m = 4 个单位）。
- 光照：暖色主光投影 + 冷色补光 + 轮廓光，环境光压低。
- 手机上自动关掉阴影、降低分辨率；PM2 / PM3 按材质合并成少数网格，减少绘制次数。

重新建模（Blender 4.2 ~ 5.x）：

```
blender -b --factory-startup -P build_etcher.py
```

## 改代码

`web/index.html` + `web/app.js` + `web/etch_core.js` 是源码。改完（或重新建模后）重新打包离线版：

```
cd tools
npm install --no-save esbuild@0.24.0 three@0.170.0
node build_offline.mjs
```

- `web/etch_core.js`：工艺模型（配方 → 速率、离子能量、选择比；每帧推进刻蚀深度、侧壁钻蚀、栅氧、光刻胶、光谱终点；跑完 5 项判定）和所有讲解文字（15 步的"现在在干什么 / 为什么"、零件说明、结果提示、预置配方、粒子名）。不碰 three.js 和页面，Node 里也能跑。
- `web/app.js`：页面、3D、动画、粒子，从 `etch_core.js` 取数和文字。

## 给 VR 用（MyVRToyBox）

VR 版在 MyVRToyBox 里（玩具室的桌面演示模式 + 以后的仿真 fab 模式），原理内容和工艺模型都以这里为准：

```
node tools/export_core.mjs        # → output/etcher_content.json（讲解文字）+ output/etcher_golden.json（标准答案）
blender -b --factory-startup -P export_ue.py -- output   # → output/etcher_ue.glb（VR 桌面模型，20 个部件）
```

- `etcher_content.json`：`etch_core.js` 里的文字和配方参数原样导出，VR 的触屏、信息牌读它，网页改了文字 VR 跟着变。
- `etcher_golden.json`：5 个预置配方 + 60 个随机配方（固定种子），用网页版的模型按 0.05 秒一步、不加噪声算出的结果。VR 的 C++ 版模型逐组对这份答案（MyVRToyBox 控制台 `toy.EtchSelfTest`）。**改了 `etch_core.js` 的公式就要重新跑 `export_core.mjs`，再照着改 C++ 版**。
- `export_ue.py`：复用 `build_etcher.py` 建模，只要工艺腔 PM1（去掉射频电源柜、EFEM、传输腔，剪掉连到电源柜的两根射频电缆和气体盒到喷嘴的进气管），按"开腔保养"能讲清楚的东西合成 20 个部件：腔体 + 机架（基座）、屏蔽罩、源匹配器、线圈、喷嘴、介质窗、气体盒、光谱仪、真空计、闸阀门、内衬、约束环、晶圆、边缘环、绝缘环、静电卡盘、升降针、偏压匹配器、摆阀、分子泵。每个部件带中文名、材料、作用（取自 `etcher_content.json`）和爆炸路线（顶上的提起来放到后面，腔里的往上抽出放到左边，腔底下的往外拉）。
  - `--check`：在拆开 25 / 50 / 75 / 100% 时检查部件之间有没有穿插（100% 时应该没有）。
  - `--preview`：渲染装配、拆开一半、拆开、俯视四张预览图（Cycles，约 3 分钟）。
  - MyVRToyBox 的 `导入刻蚀机模型.bat` 会自动跑它、导入，再把两个 json 拷过去。

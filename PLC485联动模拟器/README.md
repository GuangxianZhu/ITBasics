# PLC IO ↔ RS-485 联动模拟器

三菱 PLC 的 IO（远程、在线、通水、加热、停止、确认、急停）怎样和温水器自有的 RS-485 协议联动的演示程序。

## 运行
Windows 双击 `run_v2.bat`（v2 双向通信）或 `run_v1.bat`（v1）。
第一次会自动 `pip install panda3d`；网络装不上的话，手动装一次即可。

手动运行：
```
pip install panda3d
python plc485_sim.py      # v1
cd v2 && python app.py    # v2
```

## 画面
- 左：X0～X6 输入按钮（X5/X6 按一下就弹起，X4 急停按下锁定）、SV 设定、Y10～Y13 输出灯、暂停/速度/重置
- 中：时序图（蓝色竖线扫描）、485 TX/RX、PV 曲线；紫色虚线 = 哪个 IO 引起的命令
- 右上：3D（灯管、水流、485 报文、硬线）
- 右下：16 个用例 + 故障注入

## 操作
- 空格：暂停/继续　R：重置
- 暂停后点时序图：查看该时刻的 IO 和最近报文的逐字段解码
- ← →：移动查看光标（Shift 加大步长）　[ ]：跳到上/下一条命令帧
- 窗口 1s + 速度 0.1x：可以看清单帧约 10ms 的报文

## 要点
- 急停走硬线，不经过 485；485 只是事后补发停止并确认
- Y12「加热许可」也是硬线：通信异常时 PLC 断开它，温水器靠硬线停下
- 报警复位后 X3 要重新给上升沿才会再启动（不会自动重启）

## 换协议
协议全部在 `FakeProtocol` 类；命令处理在 `Heater.receive`。换别的协议只改这两处。

## v2：双向通信（`v2/` 文件夹）

清洗机原 IO（远程/在线/通水/加热/复位 + AD 4-20mA → Ready/过热/漏水/轻故障/重故障）
经 PLC 网关转成全串口温水器。协议框架拆成 codec / 命令表 / 点表，可切换示例协议和 Modbus RTU。
详见 `v2/README.md` 和 `双向通信方案.md`。

---

## 时序图（`时序图/` 文件夹）

槽式清洗机经 PLC 接只用串口的温水器，信号时序图分 4 部分画（启动 / 供水 / 轮询 / 报警）。
规划和通信层看 `时序图/README.md`，图看 `时序图/out/图一览.md`。改 `charts.py` 后双击 `render_charts.bat` 重新出图。
draw.io 版有中文 / 日语 / 英语三份（`时序图/out/时序图.drawio`、`时序图_ja.drawio`、`时序图_en.drawio`），翻译在 `时序图/i18n.py`。

## 网页版模拟器（`web/` 文件夹）← 现在用这个

双击 `run_web.bat`。离线网页，不用装 Python。清洗机 ↔ PLC 网关 ↔ 温水器按 `时序图/README.md` 定下来的做法实际跑，
时序图是跑出来的（分块、筛选、缩放、光标测量、导出 SVG / PNG / CSV），参数和操作脚本都能改，界面中 / 英 / 日三语。
详见 `web/README.md`。

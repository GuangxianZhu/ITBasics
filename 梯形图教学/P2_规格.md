## 1. 分层（最重要）

```
app/   ← 纯 Python，不得 import panda3d。所有"算什么、显示什么颜色、现在走到哪一步"都在这里。
ui/    ← Panda3D。只负责把 app/ 给的结果画出来、把鼠标键盘事件转给 app/。不做任何逻辑判断。
```

判断标准：**如果 ui/ 里出现了 `if plc.get(...)` 或者自己算颜色，就是放错层了。**

新增文件：

```
app/
├── __init__.py
├── draw.py          ← 梯形图 → 绘图元素列表
├── controller.py    ← 运行 / 暂停 / 单步 / 慢放
├── views.py         ← 指令表行、监视表行
└── demos.py         ← P2 用的示例程序
ui/
├── fonts.py         ← 中日文字体加载
├── ladder_view.py   ← 把 Drawing 画成 LineSegs / TextNode
├── panels.py        ← 指令表、监视表、控制按钮、输入按钮
└── app_main.py      ← ShowBase 子类，组装一切
main.py              ← python main.py 启动
tools/snapshot.py    ← 离屏截图
```

## 2. `app/draw.py` —— 绘图元素（冻结）

```python
@dataclass
class Elem:
    kind: str          # "line" | "rect" | "text"
    tag: tuple         # 语义标签，见下表
    x1: float; y1: float
    x2: float = 0.0; y2: float = 0.0     # line: 终点；rect: 右下角；text: 不用
    color: str = "idle"                  # 语义颜色名，见下表
    text: str = ""                       # text 用

@dataclass
class Drawing:
    elems: list          # [Elem]
    width: float         # 整张图宽（= 右母线 x）
    height: float        # 整张图高
    rung_top: list       # 每行（ラング）顶端的 y

def draw_program(program, plc, current_rung=None) -> Drawing
```

### 坐标系（网格单位，ui 再缩放）

- x 向右、**y 向下**。左母线在 x=0。
- 设 `W = max(1, 所有行 layout(cond).width 的最大值)`。
- 第 r 行顶端 `rung_top[r] = Σ_{j<r} (height_j + 1)`（行与行之间空 1 格），`height_j = layout(rungs[j].cond).height`。
- 触点 `(col,row)` 占 `x ∈ [col+1, col+2]`、`y ∈ [top+row, top+row+1]`，电线走在 `y = top+row+0.5`。
- 线圈（含 OUT T / OUT C / RST）占 `x ∈ [W+1, W+2]`、`y ∈ [top, top+1]`：**所有行的线圈竖向对齐**。
- 右母线 x = `W+3`。`Drawing.width = W+3`，`Drawing.height = rung_top[-1] + height_last`（空程序为 0）。
- 0~1 列之间、触点之后到线圈之间的空隙、并联分支的竖线、窄分支右侧补齐的横线，都画成 `wire`。

### 标签与颜色

| tag | kind | color | 说明 |
|-----|------|-------|------|
| `("rail_left",)` / `("rail_right",)` | line | `"rail"` | 左右母线 |
| `("contact", r, k)` | line（可多条） | `"on"`/`"off"` | 第 r 行、第 k 个触点（k = layout cells 下标）。**on = 触点导通**（常开且元件 ON，或常闭且元件 OFF），与左边有没有电无关——和 GX Works 监视一样 |
| `("label", r, k)` | text | `"text"` | 触点上方的地址，text = `"X0"` 等 |
| `("coil", r)` | line 或 rect | `"on"`/`"off"` | on = `plc.last_power[r]` |
| `("coil_label", r)` | text | `"text"` | `"Y0"` / `"T0 K50"` / `"C0 K3"` / `"RST C0"` |
| `("wire", r, …)` | line | `"power"`/`"idle"` | 第三个以后的元素随你定。有电 = power |
| `("wire_coil", r)` | line | `"power"`/`"idle"` | 进入线圈的最后一段线，power ⇔ `last_power[r]` |
| `("marker", r)` | text | `"marker"` | 只在 `current_rung == r` 时出现，text = `"▶"`，画在左母线左边 |

电线有没有电用 `plc.engine.evaluate(cond, plc.get, trace)` 的 trace 算：触点左边那段线 = 该触点的左端电压，右边那段 = trace 值。

颜色名到实际 RGB 由 ui 决定（建议：power/on = 亮绿，idle/off = 灰，rail = 白，marker = 黄）。

## 3. `app/controller.py` —— 运行控制（冻结）

```python
class Controller:
    def __init__(self, program, scan_ms=10): ...
    plc: PLC
    program: Program
    mode: str            # "run" | "pause"，初始 "run"
    speed: float         # 慢放：每个 Step 之间的秒数。0 = 全速（实时）。初始 0
    mid_scan: bool       # 正处于一轮扫描中间（已出 input，还没出 output）
    last_step: Step | None   # 最近执行的 Step，初始 None
    current_rung: int | None # last_step 是 rung 时为其行号，否则 None
    phase_text: str      # "" / "输入采样" / "执行第 N 行"（N 从 1 数）/ "输出刷新"

    def load(self, program): ...          # 换程序：新建 PLC，mid_scan=False，last_step=None，按钮状态保留
    def set_button(self, addr, pressed): ...   # 立即 plc.set_input(addr, pressed)
    def run(self): ...                    # mode="run"
    def pause(self): ...                  # mode="pause"（可以停在一轮中间）
    def step_one(self) -> Step: ...       # 前进一个 Step（接着中断的那一轮走；没有进行中的轮就开新一轮）
    def step_scan(self): ...              # 在一轮中间 → 走完这一轮；否则 → 完整走一轮
    def update(self, dt): ...             # 每帧调用
```

`update(dt)` 规则（时间一律用**整数毫秒**累计：`acc_ms += round(dt*1000)`，避免浮点误差）：
- `mode == "pause"`：什么都不做。
- `mode == "run"` 且 `speed == 0`：累计时间，每满 `scan_ms` 走一轮完整扫描（若在一轮中间，先把这一轮走完，算作一轮）。**一次 update 最多走 100 轮**，多余的累计时间丢掉。
- `mode == "run"` 且 `speed > 0`：累计时间，每满 `round(speed*1000)` 毫秒走一个 Step（`step_one`）。一次最多 1000 步。

实现提示：用 `plc.steps()` 生成器，存在 Controller 里，`step_one` 就是 `next()`，`StopIteration` 时开新的生成器。

## 4. `app/views.py` —— 表格数据（冻结）

```python
IO_NAMES = {   # 固定，中文（日文）
    "X0": "启动按钮（起動ボタン）",  "X1": "停止按钮（停止ボタン）",
    "X2": "下限液位（下限レベル）",  "X3": "上限液位（上限レベル）",
    "Y0": "给水阀（給水バルブ）",    "Y1": "排水阀（排水バルブ）",
    "Y2": "完成灯（完了ランプ）",
}

def il_rows(program) -> list[tuple]     # [(行号 或 None, 指令文本), ...]，最后一条 (None, "END")
def monitor_rows(program, plc) -> list[tuple]   # [(地址, 名称, 值文本, on), ...]
```

`monitor_rows` 顺序：X0 X1 X2 X3 Y0 Y1 Y2 固定在前；然后程序里出现过的 M、T、C（触点或输出里出现都算），各自按编号排序（M 全部在 T 前，T 在 C 前）。
- 名称：`IO_NAMES` 里有就用，没有为 `""`。
- 值：X/Y/M → `"ON"`/`"OFF"`；T → `"当前秒/设定秒"`，各保留 1 位小数，如 `"3.2/5.0"`（设定值取程序里第一条 `OUT T` 该地址的 K；没有 OUT T 时设定显示 `"-"`，如 `"0.0/-"`）；C → `"当前/设定"`，如 `"1/3"`（同理，无 OUT C 时 `"0/-"`）。
- on：`plc.get(地址)`。

## 6. 界面（ui/，Panda3D）

窗口 1280×720，标题 `PLC 梯形图教学`，背景深灰。布局（P3 之前右侧水槽区先放 X0~X3 输入按钮）：

```
┌─────────────────────────────────────────┬──────────────────┐
│ 示例: [自保持][定时器][计数器][双线圈]      │                  │
├─────────────────────────────────────────┤  输入（P3 换成水槽）│
│                                         │  [X0 启动] 按住=ON │
│        梯形图区（自动缩放填满）             │  [X1 停止] 按住=ON │
│                                         │  [X2 下限] 点=切换 │
│                                         │  [X3 上限] 点=切换 │
├────────────────────┬────────────────────┤                  │
│ 指令表 il_rows       │ 监视 monitor_rows  │                  │
│ 当前行的指令底色高亮   │ on 的行绿色         │                  │
├────────────────────┴────────────────────┴──────────────────┤
│ [▶运行][⏸暂停][单步][单轮]  慢放 ━━●━━ (0~1秒)  状态: 执行第2行 │
└────────────────────────────────────────────────────────────┘
```

- 每帧：`controller.update(dt)` → `draw_program(...)`、`il_rows`、`monitor_rows` → 重画。重画可以每帧整个重建（程序很小，没关系），但**旧节点必须 removeNode**，不能越积越多。
- 梯形图：`ui/ladder_view.py` 把 `Drawing` 映射到屏幕区域（等比缩放、居中）。line → `LineSegs`（线宽 2~3），rect → 填充矩形或 LineSegs 框，text → `TextNode`。
  - 常开触点画 `─┤ ├─`（两条竖线），常闭再加一条斜线；线圈画 `( )`（可以用两段折线或圆弧近似）。具体画法自由，但同一 tag 的元素用同一颜色。
- X0/X1 按钮是**瞬时**的：鼠标按下 = ON，松开 = OFF（DirectButton 绑定 `DGG.B1PRESS` / `DGG.B1RELEASE`）。键盘 `0`/`1` 按住也行。X2/X3 是切换开关。
- 指令表：当前行（`controller.current_rung`）对应的所有指令加底色。
- 键盘：空格 = 运行/暂停切换；`→` = 单步；`↓` = 单轮。
- 字体：按 `交接文档.md` 第 4 节加载中日文字体，所有 TextNode / DirectGUI 都要设。
